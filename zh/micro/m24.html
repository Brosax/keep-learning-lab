Sistema de reloj (UCS)

时钟系统：从振荡器到 ACLK / MCLK / SMCLK

10 个要点 阅读约 20 分钟

CPU 和每个外设都踩着时钟的节拍工作。节拍越快，算得越快，也越费电；时钟越稳，越贵。MSP430F5529 的 UCS (Unified Clock System)——统一时钟系统，把这道选择题交给程序员：5 个振荡器产生 6 个 fuente de reloj (ES) / clock source (EN)——时钟源，再经过选择器和分频器，变成几路 señal de reloj (ES) / clock signal (EN)——时钟信号。这一章从"上电默认为什么是 1048576 Hz"讲起，一直讲到晶体坏了会发生什么，最后读一遍示例程序 UCS1_XT2.c。

§0一棵时钟树 M24.1

CPU 和每一个外设，需要以同一个频率工作吗？它们需要一直开着吗？¿Necesitan la CPU y los periféricos la misma frecuencia, y estar siempre activos?

两个问题的答案都是"不需要"。频率越高，处理越快，耗电也越多；而且很多时候 CPU 和外设只是在等事件。所以 UCS 提供多个时钟源、多路时钟信号，每一路都可以单独选源、分频、关闭。整棵树分三层：

Auxiliary Clock

ACLK

常作 Timer、UART 等外设的低频同步时钟。SR 的 OSCOFF = 1 可以关掉它。分频：DIVA；另有 DIVPA 把 ACLK/n 送到引脚。

Master Clock

MCLK

CPU 的时钟（也可以给外设）。SR 的 CPUOFF = 1 关掉它——CPU 就停了。分频：DIVM。

SubMain Clock

SMCLK

多数外设可选的高频时钟。UCSCTL6 的 SMCLKOFF = 1 关掉它。分频：DIVS。

UCS = 5 个振荡器（+ MODOSC）→ 6 个时钟源 → 3 路可选源、可分频、可单独关闭的时钟信号（+ MODCLK）。用谁、多快、什么时候关，由软件决定。

UCS 的控制寄存器叫 UCSCTLx（16 位，也能按字节访问 UCSCTLx_L / UCSCTLx_H），偏移从 00h 起每个加 2，族里最多有 UCSCTL0–UCSCTL9。F5529 没有 UCSCTL9，所以只用 UCSCTL0–UCSCTL8（全部复位值和位域见 §5 的表）。关 ACLK、MCLK 的 OSCOFF、CPUOFF 位在 SR 里，和低功耗模式直接相关，见 M26。

§1四个"定频"振荡器 M24.2 · M24.3

要精确，还是要省电？要便宜，还是要快？VLO, REFO, XT1 y XT2: precisión, consumo y coste.

DCO 留到 §2。其余四个振荡器的频率基本是固定的，区别在精度、功耗和要不要外接元件：

振荡器频率精度特点
VLO≈ 10 kHz（典型 9.4，范围 6–14 kHz）差：0.5 %/°C、4 %/V片内、最省电、最便宜；只用于不需要准确时间基准的场合
REFO32768 Hz（片内校准）25 °C、3 V 时 ±1.5 %；全温度范围 ±3.5 %片内；不用时不耗电，工作时约 3 µA，比 XT1 费电；起振约 25 µs；可作 FLL 参考；XT1 不稳定时由它顶上
XT132768 Hz 手表晶体（LF）；旁路输入 10–50 kHz晶体级外接晶体，负载电容在片内（XCAP）；起振慢：XT1DRIVE = 3、12 pF 时典型 0.5 s，XT1DRIVE = 0、6 pF 时 1 s；F5529 只支持 LF 模式
XT24–32 MHz 晶体；旁路输入 0.7–32 MHz晶体级特性和 XT1 的 HF 模式一样；片内没有负载电容，要在两脚外接；4 MHz 时约 200 µA，比 XT1 费电得多；LaunchPad 上接的是 4 MHz（见 UCS1_XT2.c 的注释）

这些振荡器都是按需打开的：某路时钟（ACLK、MCLK、SMCLK）选了它，或者它作 FLL 参考而 DCO 又在驱动某路时钟，而且那路时钟在当前模式下是开着的，它才运行。

XT1、XT2 的控制位（UCSCTL6）

把 UCS 方块图里 XT1、XT2 的部分单独拿出来看，图上标出的控制位全在 UCSCTL6 里：

再看 UCSCTL6 的位图，复位值 C1CDh 逐位拆开：

  • XTS（bit 5）：0 = LF（10–50 kHz），1 = HF（4–32 MHz）。F5529 没有 XT1 高频模式的硬件，XTS 必须保持 0。
  • XT1BYPASS（bit 4）：0 = 用晶体；1 = XIN 直接输入外部时钟，晶体振荡电路关掉省电，XOUT 当普通 I/O 用。
  • XCAP（bits 3–2）：3 档片内电容，或者外接。有效负载电容：XCAP = 1、2、3 → 约 5.5、8.5、12 pF；XCAP = 0 只剩约 2 pF 寄生电容，要在 XIN、XOUT 外接电容。复位值 3（12 pF）。
  • XT1DRIVE（bits 7–6）：驱动电流。复位时是最大值 3，起振快而可靠；稳定后可以调小省电。LF 模式下 XT1DRIVE = 1、2、3 比最低档多耗约 0.075、0.17、0.29 µA。
  • XT1OFF（bit 0）：复位值 1 = 没有时钟或 FLL 用它就关；写 0 = 只要引脚已经交给 XT1（PSEL）而且不是旁路模式，就一直开着。
  • XT2OFF（bit 8）、XT2BYPASS（bit 12）、XT2DRIVE（bits 15–14）：XT2 的同类位。XT2DRIVE 选频率段：00 = 4–8 MHz（电流最小）、01 = 8–16、10 = 16–24、11 = 24–32 MHz。
复位后引脚不是时钟脚

XT1 的 XIN/XOUT 是 P5.4/P5.5（80 脚 PN 封装的 12、13 脚），XT2 的 XT2IN/XT2OUT 是 P5.2/P5.3（69、70 脚）。复位后它们都是普通 I/O，必须先把对应的 P5SEL 位置 1，晶体才会起振。旁路模式下只需要设 XIN（或 XT2IN）那一位。§5 和 §7 的故事都从这里开始。

§2DCO：范围、tap 和调制器 M24.4

一个片内的 RC 振荡器，怎样调到想要的频率？DCO: DCORSEL, DCO y MOD.

DCO (Digitally Controlled Oscillator)——数控振荡器，是片内的 RC 振荡器。它起振极快（PUC 后不到 5 µs CPU 就能开始执行代码），但不精确：频率随温度、电源电压变化，芯片和芯片之间也不一样。频率由三组位决定：

  • DCORSEL（UCSCTL1 bits 6–4，3 位）：选 8 个标称频率范围中的一个，改变 DC 发生器的电阻、也就是注入电流。复位值 2。
  • DCO（UCSCTL0 bits 12–8，5 位）：把选中的范围分成 32 个 tap——档位，每一档比前一档高约 8 %。复位值 0。
  • MOD（UCSCTL0 bits 7–3，5 位）：调制器，在 tap DCO 和 tap DCO+1 之间切换，得到中间频率。UCSCTL1 的 DISMOD = 1 关掉调制器。
DCORSELDCO = 0（MOD = 0）DCO = 31（MOD = 0）建议目标区间
00.07–0.20 MHz0.70–1.70 MHz0.20–0.70 MHz
10.15–0.36 MHz1.47–3.45 MHz0.36–1.47 MHz
2 · 复位值0.32–0.75 MHz3.17–7.38 MHz0.75–3.17 MHz
30.64–1.51 MHz6.07–14.0 MHz1.51–6.07 MHz
41.3–3.2 MHz12.3–28.2 MHz3.2–12.3 MHz
52.5–6.0 MHz23.7–54.1 MHz6.0–23.7 MHz
64.6–10.7 MHz39.0–88.0 MHz10.7–39.0 MHz
78.5–19.6 MHz60–135 MHz19.6–60 MHz

表中每格是 min–max。复位后 DCORSEL = 2、DCO = MOD = 0：如果 FLL 关着，上电时 DCO 就在 0.32–0.75 MHz 之间某处。同一 tap 下，相邻两个范围差 1.2–2.3 倍；1 MHz 附近的漂移约 0.1 %/°C、1.9 %/V。

为什么不直接查表设频率？

举个例子：想要 6 MHz，查表可以设 DCORSEL = 5、DCO = MOD = 0——可这时只能保证频率在 2.5–6.0 MHz 之间。范围这么宽，手动设 tap 根本不知道实际频率是多少。tap 和 MOD 的精细调节，只有在有一个稳定参考时才有意义。这就是 FLL（§3）。

调制器的规则：一个调制周期是 32 个 DCOCLK 周期，其中 MOD 个周期用 fDCO+1，其余 32 − MOD 个用 fDCO。MOD = 0 时调制器不起作用。拖动滑块看图样；"积分器 ±1"按钮模拟 FLL 每次改一个计数：MOD 从 31 再加 1 会回到 0，同时 DCO 进一档。

t̄ = [(32 − MOD)·t_DCO + MOD·t_DCO+1] / 32

上式是平均周期 t̄（除以 32）；也可以写成不除以 32 的整段时间 t₃₂ = 32·t̄，两者是同一件事。黄色格子的位置：MOD 的每一位管一组均匀分开的周期——bit 0 管第 16 个，bit 1 管第 8、24 个，bit 2 管 4、12、20、28，bit 3 管 2、6、10…30，bit 4 管全部奇数周期；所以 MOD = 1 时唯一的 DCO+1 周期在正中间，MOD = 16 时两种周期交替，MOD = 31 时只有第 0 个周期用 fDCO。DCO = 31 时 MOD 不再起作用（已经是最高档）。把能量分散到两个频率上，还能减小电磁干扰（EMI）。FLL 工作时，DCO 和 MOD 都由硬件自动改写。

§3FLL：把 DCO 锁在参考上 M24.5

RC 振荡器会漂，晶体很稳。能不能让 DCO 借晶体的稳？Frequency Locked Loop: enganchar el DCOCLK a una fuente de referencia.

FLL (Frequency Locked Loop)——锁频环，核心是一个 10 位的 integrador (ES) / frequency integrator (EN)——积分器（其实是一个加减计数器）。它的值直接就是 UCSCTL0 里的 DCO（高 5 位）和 MOD（低 5 位）。DCOCLK 因此和参考时钟一样稳定。

f_DCOCLK = D·(N+1)·f_FLLREFCLK/n　　f_DCOCLKDIV = (N+1)·f_FLLREFCLK/n

这就是锁定条件 fDCOCLK / (D·(N+1)) = fFLLREFCLK / n 的另一种写法。N + 1 最小是 2：FLLN 写 0 会被当成 1。四个字段的位置和编码：

字段位置编码含义
FLLDUCSCTL2 · bits 14–12000…101D = 1, 2, 4, 8, 16, 32（110、111 保留，按 32）。复位 001 → D = 2
FLLNUCSCTL2 · bits 9–010 位N（必须 > 0）。复位 0x1F → N = 31
SELREFUCSCTL3 · bits 6–4000 / 010 / 101XT1CLK / REFOCLK / XT2CLK（其余编码保留：001 → XT1CLK，011、100 → REFOCLK，110、111 → XT2CLK）。复位 000

有些资料正文说 FLLN 在 UCSCTL3，但它自己的寄存器图和 TI 手册都把 FLLN 放在 UCSCTL2（和 FLLD 一起）。按寄存器图记。UCSCTL2 的复位值是 101Fh；UCSCTL3 里是 SELREF 和 FLLREFDIV。

关掉 FLL

SR 里的 SCG0 或 SCG1 置 1，FLL 就停了：DCO 停在当时的 DCO、MOD 值上继续跑，不再被校正，温度和电压的变化又会直接影响频率。中断响应会自动清掉 SCG1、CPUOFF、OSCOFF，但不清 SCG0——这一点在 M26 的低功耗模式里会用到。

换档要时间：每跨一个 tap 需要 n·32 个 FLLREFCLK 周期，最坏 n·32·32 个。n = 1、参考 32768 Hz 时，最坏约 31 ms。所以改完 FLL 设置不要立刻依赖新频率。

§4三路时钟：选源与分频 M24.6

6 个时钟源、3 路信号，各接哪一个？各跑多快？SELA, SELS, SELM (UCSCTL4) y DIVA, DIVS, DIVM (UCSCTL5).

UCS 的输出一共四路：ACLK/n、ACLK、MCLK、SMCLK，外加 MODCLK。ACLK、MCLK、SMCLK 的通路都是 Enable Logic → 8 选 1 选择器 → 分频器 → 输出，三路结构完全一样，只是开关位不同（OSCOFF、CPUOFF、SMCLKOFF）。以 ACLK 为例：

MCLK 的上限

选择器在 MCLK > 8 MHz 时会报警：按推荐工作条件，复位后的核心电压等级 PMMCOREV = 0 只允许 MCLK 到 8 MHz，更高要先提高核心电压（PMM 模块）。DCO 表上的 135 MHz 只是振荡器的范围，不是 CPU 能用的频率。

DIVPA 把 ACLK 再分频后送到外部引脚（ACLK/n），不影响内部的 ACLK。§1 的引脚图上能看到三路时钟的输出脚：P1.0/TA0CLK/ACLK（21 脚，输出的是 ACLK/n）、P2.2/TA2CLK/SMCLK（31 脚）、P7.7/TB0CLK/MCLK（60 脚）；按 M14 的方法设 PxSEL、PxDIR 选外设功能，就能用示波器量时钟。另外，外设可以通过 ACLK_REQ、MCLK_REQ、SMCLK_REQ 主动请求它用的时钟，即使低功耗模式本来会关掉它；UCSCTL8 的 ACLKREQEN、MCLKREQEN、SMCLKREQEN（复位值都是 1）允许这种请求。这和 M26 有关。

§5上电默认：为什么是 1048576 Hz M24.7

什么都不配置，CPU 跑多快？ACLK 又从哪里来？Configuración de arranque del módulo UCS.

PUC 之后，UCS 的寄存器回到复位值。默认配置本来"想"用 XT1，可 XT1 的引脚这时还是普通 I/O。看系统怎样一步步自救：

f_DCOCLK = 2·(31+1)·32768/1 = 2097152 Hz；f_MCLK = f_SMCLK = f_DCOCLKDIV = 1048576 Hz

计算的起点：DCORSEL = 2、DCO = MOD = 0；FLLD = 001 → D = 2；FLLN = 0x1F → N = 31；FLLREFDIV = 000 → n = 1。

§6振荡器故障 M24.8

晶体坏了、掉了，或者根本没配置——CPU 会停吗？软件怎么知道？Módulo de detección de fallo de oscilador.

出故障的是结果
ACLK、MCLK 或 SMCLK 的源（XT1 LF 以外）这路时钟自动改用 DCOCLKDIV；SELx 不变
ACLK、MCLK 或 SMCLK 的源是 XT1 LF这路时钟自动改用 REFOCLK；SELx 不变
FLL 参考是 XT1 LFFLLREFCLK 自动改由 REFO 提供（§5 的情形）
FLL 参考是 XT1 HF 或 XT2没有参考脉冲，积分器一直往下数，DCO 掉到 tap 0 → DCOFFG 置位

简化的记法“XT1 HF 故障转 DCO、XT1 LF 故障转 REFO”只是上表的两个特例。DCOCLKDIV 在最低 tap 也有输出，所以故障期间 CPU 仍能执行代码、处理 NMI。N 设得太大、DCO 被推到 tap 31 时，DCOFFG 同样会置位。

两种处理方式：启动时轮询，直到所有 flag 都清得掉（§7 的 do…while）；或者运行中用 UNMI 中断随时接住故障。后者的骨架（示意）：

SFRIE1 |= OFIE;                          // 打开振荡器故障中断（UNMI 不受 GIE 控制） #pragma vector=UNMI_VECTOR              // 61 号，0FFFAh__interrupt void UNMI_ISR(void) {    switch (__even_in_range(SYSUNIV, 0x08)) {    case 0x04:                           // OFIFG：振荡器故障        do {                             // 清 flag，直到故障消失            UCSCTL7 &= ~(XT2OFFG + XT1LFOFFG + DCOFFG);            SFRIFG1 &= ~OFIFG;        } while (SFRIFG1 & OFIFG);        break;    default: break;    }}

真实应用里不宜在 ISR 里死等（见 M21 §8：ISR 要短）；这里只是演示 flag 的清法。SYSUNIV：02h = NMIIFG、04h = OFIFG、06h = ACCVIFG。

照原样为什么不能运行？

原程序照原样不能运行。代码里给了两个选项，都被注释掉了：

按 §6 的 fail-safe 规则可以推出原因：ACLK（SELA = 000）和 FLL 参考（SELREF = 000）仍然要用 XT1，可 P5.4/P5.5 没有配置，XT1 不起振 → XT1LFOFFG 每次刚清掉又被置 1 → OFIFG 一直是 1 → do…while 永远出不来。取消其中一个选项的注释即可。

P5DIR &= ~BIT4;                         // P5.4 = XINP5DIR |= BIT5;                          // P5.5 = XOUTP5SEL |= BIT4 | BIT5;                   // 引脚交给 XT1UCSCTL6 &= ~(XT1DRIVE0 | XT1DRIVE1);    // XT1DRIVE = 0：电流最小

XT1 开始起振，稳定后故障消失，循环结束。结果：ACLK = FLLREFCLK = XT1CLK。注意这里在循环之前就把 XT1DRIVE 降到 0，起振会慢一些（典型值：XT1DRIVE = 0 约 1 s，= 3 约 0.5 s）。

UCSCTL3 |= SELREF_2;                    // FLL 参考 = REFOCLK（000 | 010 = 010）UCSCTL4 |= SELA_2;                      // ACLK = REFOCLK（000 | 010 = 010）

XT1 没人用了，加上 XT1OFF 的复位值是 1，它就保持关闭，不再报故障。结果：ACLK = FLLREFCLK = REFO。这两行用 |= 没问题，因为 SELREF、SELA 的复位值是 000。

陷阱：用 |= 和 = 改多位字段

文件里专门留了两条"不幸的指令"（INSTRUCCIÓN DESAFORTUNADA）：

  • UCSCTL4 = SELS_5; 用 = 覆盖了整个寄存器：SMCLK = XT2CLK 没错，但 SELA、SELM 也被写成 000 → ACLK = MCLK = XT1CLK（XT1 没起振时实际是 REFO 的 32768 Hz）。
  • UCSCTL4 |= SELS_2; 本意是 SMCLK = REFO。可 SELS 原来是 100（或者已经是 101），OR 之后变成 110 或 111——保留编码，在 F5529 上等于 XT2CLK，根本不是 REFO。

|= 只能把 0 变成 1。改多位字段要先清、再写：

UCSCTL4 &= ~(SELS0 | SELS1 | SELS2);    // 先把 SELS 清成 000UCSCTL4 |= SELS_2;                      // 再写 010 → SMCLK = REFOCLK

软件延时跟着 MCLK 走 M24.10

__delay_cycles(n) 是编译器的内建函数，生成正好消耗 n 个 MCLK 周期的代码。所以同一行代码，换了时钟，延时就变了：

t = 周期数 / f_MCLK；10⁶ / 4 MHz = 0.25 s；10⁶ / 1048576 Hz ≈ 0.954 s

自测 12 题

根据本章内容编写的练习题。每题只能点一次，答完会显示解析。

01MCLK 选的是 XT2CLK（SELM = 101），XT2 突然停振。会怎样？

B。fail-safe：源出故障就改用 DCOCLKDIV（只有 XT1 LF 例外，改用 REFO），SEL 位不变（§6）。

02哪个振荡器最省电，但精度最差？

C。VLO 约 10 kHz（6–14 kHz），随温度、电压变化很大，用于不需要准确时间基准的场合（§1）。

03在 MSP430F5529 上，UCSCTL6 的 XTS 位应该是？

A。F5529 没有 XT1 高频模式的硬件，XTS 必须保持 0（§1）。

04UCSCTL6 配好了，可 XT1 的 32768 Hz 晶体仍然不起振。最可能漏了什么？

A。复位后 XIN/XOUT（P5.4/P5.5）是普通 I/O，要先设 PSEL（§1、§5）。

05DCO 的 32 个 tap 由哪个字段选择？

B。DCORSEL 选 8 个范围之一，DCO 在范围内选 32 个 tap 之一，MOD 在相邻两个 tap 之间调制（§2）。

06MOD = 8 时，一个调制周期里发生什么？

D。32 个 DCOCLK 周期中，MOD 个用 tap DCO+1，其余用 tap DCO（§2）。

07fFLLREFCLK = 32768 Hz，n = 1，FLLN = 63，FLLD = 001。DCOCLKDIV 是多少？

B。(N + 1)·f/n = 64 × 32768 = 2097152 Hz。4194304 Hz 是再乘 D = 2 的 DCOCLK；2064384 忘了 +1（§3）。

08下面哪个操作会关闭 FLL？

A。FLL 关闭后 DCO 停在当前 tap/MOD 上，不再被校正。DISMOD 只关调制器（§3）。

09PUC 之后什么都不配置，MCLK 是多少？

C。MCLK = DCOCLKDIV = (31 + 1) × 32768 = 1048576 Hz；2097152 Hz 是 DCOCLK（§5）。

10UCSCTL4 = 0x0044 表示什么？

A。SELA（bits 10–8）= 000 = XT1CLK；SELS（6–4）= 100、SELM（2–0）= 100 = DCOCLKDIV。这正是复位值（§4）。

11软件清掉 XT1LFOFFG，但 XT1 仍然没有起振。结果是？

B。故障 flag 由硬件置位、软件清除；原因还在就会再置位（§6）。这也是 §7 的故障循环会卡住的原因。

12UCSCTL4 = 0x0044 时执行 UCSCTL4 |= SELS_2;，SMCLK 的源变成什么？

C。100 | 010 = 110。|= 不能把 1 变回 0，要先清字段再写（§7）。
