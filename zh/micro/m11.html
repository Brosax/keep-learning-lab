§0微控制器在哪里 M11.1

一个联网的小物件里，装的是微控制器还是微处理器？¿Qué sistema empotrado forma parte del objeto?

物联网里的物件要在本地处理信息，这种处理能力通常由一个 sistema empotrado (ES) / embedded system (EN)——嵌入式系统提供。选哪一种，要看四件事：要处理多少种不同的任务（contextos）、负载多重、成本上限、有没有功耗限制。候选有微控制器、微处理器、DSP、FPGA、协处理器，以及混合系统。

两个例子：任务种类少、负载低、要低功耗低成本 → 微控制器；任务种类少但计算非常密集 → FPGA 可能更好。

microcontrolador

任务少 · 负载低

要低功耗、低成本，不需要完整 SO。外设偏简单。本课的 MSP430F5529 就是这一类。

microprocesador

任务多 · 要同时执行

很多不同的任务、有些要并行，就离不开操作系统；完整 SO 需要 MMU。总线层级和外设都更复杂。

FPGA

任务少 · 计算密集

例：任务种类不多，但每一项的计算量都很大时，FPGA 可能是更好的选择。

MCU 和 MPU 有同样的四种方块（CPU、存储器、外设、总线）；区别在复杂度：总线层级、有没有 MMU（能否运行完整 SO）、外设复杂度，以及随之而来的功耗和成本。

§1MSP430 家族与 F5529 M11.2

为什么 MSP430 经常出现在靠电池供电的设备里？Bajo coste y ultra bajo consumo.

Texas Instruments 有好几个嵌入式家族，MSP430 是其中之一。层级是：家族 MSP430 → 子家族 MSP430x5xx → 系列 MSP430F5xx → 本课用的 MSP430F5529。同一子家族的器件共享同一种架构（供电电压、工作频率、低功耗模式、存储器类型……），彼此的差别在存储器大小、外设和封装。在 TI 的产品线里，MSP430 属于 MCU 一栏：16 位超低功耗，最高 25 MHz、最多 512 KB Flash，单价约 0.25–9 美元；各子家族之间比较，F5529 所在的 F5x/6x 是“Low Power + Performance”一档，也是这张对比表里唯一带 USB 的一档。

这个家族的特点：

  • 超低功耗：低电压供电（具体电压见下面的框）、灵活的时钟系统带来多种低功耗模式、能自主工作的"智能"外设。所以适合电池供电的应用。
  • Von Neumann、RISC、16 位的 CPU：指令少而简单、执行快（§3）。
  • 外设多、性能高：定时器、通信、转换器、LCD 控制器……
  • 成本低：完整的开发套件和芯片都很便宜。
  • 开发和调试方便：免费的 IDE，加上芯片内置的、基于 JTAG 的调试系统：暂停程序、单步、断点、查看内存和寄存器。
电压 · 两个数字

有些资料写的供电范围是 0.9–3.6 V；F5529 的数据手册给的是 1.8–3.6 V。

微控制器是一种可编程的数字电子系统，一般的方块图如下：

F5529 的外设（括号里是下面方块图和选型表里的细节）：

  • 灵活的时钟系统（UCS：MCLK 给 CPU，ACLK、SMCLK 给外设）
  • 电源管理系统（PMM：LDO、SVM/SVS、brownout）
  • 8 个 E/S 端口 P1–P8，共 59 个引脚（P8 只有 3 个），加上和 JTAG 共用的 PJ 4 个，就是选型表里的 63 个 I/O；P1、P2 能产生中断和唤醒

  • 4 个定时器：TA0（5 个 CC 寄存器）、TA1（3）、TA2（3）、TB0（7）
  • RTC 模块（RTC_A）
  • CRC 生成模块（CRC16）
  • 3 通道 DMA
  • 12 位 ADC（ADC12_A：200 ksps，16 通道 = 14 外部 + 2 内部）

在选型表里，F5529 是 F55xx 的最后一行：128 KB Flash、8 + 2 KB RAM（多出的 2 KB 是 USB RAM）、63 个 I/O、80 脚 LQFP 封装。

periférico (ES) / peripheral (EN)——外设，给微控制器专门的功能，并把它和外部世界连起来。外设分成两组：

Periféricos internos · 内部外设

集成在芯片里，不和外部相连，给 MCU 增加功能。例子：watchdog、时钟模块、低功耗模块、硬件乘法器。很多 MCU 的 ALU 只会加减，乘法交给硬件乘法器这个外设来做。

Periféricos externos · 外部外设

也集成在芯片里，但有通往外部的通道（E/S 端口），用来连接传感器、执行器、无线模块等外部器件，收发信息。

很多器件采用interfaz estándar (ES) / standard interface (EN)——标准接口：从物理层到协议层都有规定，例如串行接口 SPI 和 I2C。MCU 用硬件实现这些接口，就能直接和它们对话。一个例子：一块 MSP430F5529 通过 I2C 挂在应用处理器旁边，当一直开着的协处理器（always-on co-processor），替它管理传感器：

MSP430 的卖点是超低功耗和低成本；F5529 属于 x5xx 子家族，在一块芯片上集成了 CPUx、128 KB Flash、10 KB RAM 和一大组外设。外设分内部（不连外部）和外部（经端口连外部）。

§2CPU 和存储器：看哪些参数 M11.3

说一块单片机是"16 位"的，这个 16 指的是什么？Longitud de palabra, capacidad de memoria, arquitectura…

选型时，CPU 和存储器是最先要看的两个方块，各有一组参数，切换着看：

  • longitud de palabra (ES) / word length (EN)——字长：一条指令最多处理多少位，和数据总线的宽度有关（8、16、32…）。说"16 位单片机"，说的就是它。
  • capacidad de memoria——寻址能力：一个地址能选中多少个位置，和地址总线有关：n 位地址 → 2n 个位置。
  • velocidad de proceso——处理速度：执行指令要多久，主要由 CPU 的时钟频率决定（kHz – MHz – GHz）。
  • conjunto de instrucciones——指令集：算术、逻辑、条件……
  • modos de direccionamiento——寻址方式：怎样找到操作数（寄存器、变址、立即数……）。
  • registros——寄存器：CPU 内部存放操作数的寄存器有几个、多宽、各干什么（§6）。
  • organización de la memoria——数据在内存里的存放格式：little endian 还是 big endian（§5）。
  • arquitectura——指令的数量和功能：CISC（Complex Instruction Set Computer）指令多而复杂，减少访存次数，但 CPU 也复杂；RISC（Reduced Instruction Set Computer）指令少而简单、执行快，CPU 更简单。
  • capacidad de almacenamiento——容量：位置数 × 每个位置的大小。例：2 KB 的存储器有 2048 个字节大小的位置。
  • modo de acceso——访问方式：secuencial（顺序，要先经过前面的位置）、aleatorio（随机，任意位置直接访问，RAM）、asociativo（相联，用内容的一部分去查找，caché）。
  • tiempo de acceso——完成一次读、写、刷新等操作的延迟。
  • mutabilidad——能否修改：只读，或可读写。
  • volatilidad——断电后是否保持：volátil（易失，信息丢失）或 no volátil（非易失）。

按这些参数，单片机里常见的存储器分成三支：ROM 家族放程序，RAM 放数据，FRAM 两样都能放。

类型记号断电后读 / 写放什么要注意
ROM 家族NV保持（非易失）Máscara：R（只读）；PROM、EPROM、EEPROM、Flash：Rw程序Rw 是可读写，但写比读慢。
↳ FlashNV · Rw保持（非易失）读很普通；写得慢程序代码、常量数据按块、段组织；写一个位置要用更高的电压，并且要对整块或整段编程。原型开发时，成本低、好烧写，是 ROM 家族里的首选。
FRAMNV · RW保持（非易失）可读可写程序，也可以放数据单元是铁电电容，读出不破坏数据，功耗很低；缺点是读速度低于 8 MHz，不适合高速处理器。
RAMV · RW丢失（易失）可读可写，简单变量、pila（栈）、montículo（堆）程序运行时的数据都在这里。分 SRAM 和 DRAM；DRAM 又有 FPM、EDO、BEDO、SDRAM、DDR，越往后越快。

记号：V 易失 · NV 非易失 · R 只读 · Rw 可读写（写更慢）· RW 可读写。

原则：程序要在断电后还在，所以放非易失存储器（ROM 家族，例如 Flash，或 FRAM）；变量、栈和堆要频繁读写，所以放 RAM（或 FRAM）。F5529 用的是 Flash + RAM。

"16 位"指字长（数据总线宽度）；寻址能力由地址总线决定（n 位 → 2n 个位置）。程序放非易失、写得慢的 Flash，变量、栈和堆放易失、好读写的 RAM。

§3一组总线还是两组 M11.4 · M11.5

CPU 要先取一条指令，再取这条指令要处理的数据。这两件事能同时做吗？Arquitectura Harvard vs Von Neumann.

答案取决于存储器怎样和 CPU 相连（下面是非常简化的示意）：

放到 MSP430 上：

  • Von Neumann：程序和数据用同一个存储空间。
  • 16 位：数据总线 16 位，所以字长是 16 位；CPU、存储器、外设之间一次传输最多 16 位。但 CPU 既能按字（palabra，16 位）也能按字节（byte，8 位）访问数据。
  • RISC：一小组简单、执行快的指令。

16 位地址和 20 位地址 M11.5

地址总线决定能寻址多大的空间。MSP430 里每个地址对应 1 个字节（字节是它处理的最小信息单位），所以：

N = 2^n　　2^16 = 65 536 B = 64 KB　　2^20 = 1 048 576 B = 1 MB

n 位地址 → 2n 个位置；1 KB = 1024 B，1 MB = 1024 KB。0x 前缀表示十六进制，另一种写法是在后面加 h：十进制 1024 = 0x400 = 0400h。

CPUx 向后兼容

CPUx 有专门的寻址方式和指令去访问 64 KB 以上的区域，同时完全兼容老的 MSP430 CPU。为了兼容，F5529 把外设、校准信息、RAM 和一部分 Flash 都集中在最低的 64 KB 里（§4）。

MSP430 是 Von Neumann 架构：程序和数据共用一个存储空间和一组总线，依次访问。16 位地址 → 64 KB；F5529 的 CPUx 用 20 位地址 → 1 MB，但关键的东西都放在兼容的最低 64 KB 里。

§4内存映射 M11.6

地址 0x1C00 里放的是什么？0xFFDE 呢？El mapa de memoria.

mapa de memoria (ES) / memory map (EN)——内存映射，说的是地址怎样分配给系统里能被访问的各个部分。这些部分分三类：CPU 的特殊寄存器；E/S 外设的配置寄存器（periféricos mapeados en memoria——存储器映射的外设，像访问内存一样访问它们）；存放数据和程序的存储器。

规则只有一条：每个地址只对应一个部分，每个部分只有一个地址。描述时分两层：funcional（功能层：这个地址用来干什么——程序、数据、中断向量……）和 físico（物理层：这个地址上是什么器件——Flash、RAM、外设寄存器……）。同一子家族的芯片共享同一张映射，差别只在 Flash 和 RAM 的大小。F5529 有 128 KB Flash 和 10 KB RAM。

下面这张表列出 F5529 的每一段。输入一个地址，或者点一行，看它落在哪里：

外设有字节宽，也有字宽

外设区里有 8 位的外设，也有 16 位的外设。对 8 位外设做字访问，结果不可预测。这就是为什么后面配置端口时，P1DIR、P1OUT 这些寄存器都按字节去写。

F5529 的低 64 KB 从下往上：外设 4 KB（0x0000）→ BSL 2 KB（0x1000）→ 信息 Flash 512 B（0x1800）→ 空闲 512 B（0x1A00）→ RAM 10 KB（0x1C00–0x43FF）→ Flash（从 0x4400 开始，共 128 KB，延伸到 0x243FF）；最顶端 0xFF80–0xFFFF 是中断向量表。

§5一个字，两个字节 M11.7

内存按字节编号，可一个字有两个字节。哪一个放在前面？¿Cómo quedan almacenados los bytes y las palabras?

先对上几个词。字长是 16 位，但最小的访问单位是字节，所以存储空间按字节编号：1 MB = 220 = 1 048 576 个字节位置。

  • 一个字由 2 个字节组成：权重低的叫 LSB (Least Significant Byte)——低字节，权重高的叫 MSB (Most Significant Byte)——高字节。
  • 一个字节由 8 位组成：最低位叫 LSb（Least Significant bit），最高位叫 MSb（Most Significant bit）。注意大小写：B 是 byte，b 是 bit。
  • 多字节数据在内存里的排列格式叫 endianness——字节序。Little endian：LSB 放在低地址，MSB 放在高地址。Big endian：正好相反。

CPUx 能访问四种单位：单个位（bits individuales）；字节，奇偶地址都行；字（16 位），只能偶地址；20 位 address-word，只能偶地址，占两个字，第 19–16 位放在第二个字的最低 4 位。

mem[A] = LSB　　mem[A+1] = MSB　　（A 为偶数）

寄存器里的约定见 §6：比 20 位短的数据放在寄存器的低位部分，高位清零。

MSP430 是 little endian：低字节在低地址。字节可以放在任何地址；字和 20 位数据只能从偶地址开始，20 位数据占两个字。

§6CPUx 的 16 个寄存器 M11.8

CPU 里离运算最近、最快的存储，是哪 16 个格子？Los registros de la CPUx.

F5529 的 CPU 是 CPUx (CPU extendida)——扩展 CPU：20 位地址总线，能访问 1 MB，带有访问这些区域的专用寻址方式和指令，并且和老的 MSP430 CPU 向后兼容。它有 16 个寄存器 R0–R15，既能放数据，也能放"数据在哪里"的地址。除了状态寄存器 SR 为了兼容仍是 16 位，其余都是 20 位。

PC 的三个特点

  • 20 位，总是指向下一条要读取 / 执行的指令（或指令的下一部分）。
  • 总是偶地址：每条指令的长度都是偶数个字节（2、4、6 或 8），而且按字读取；硬件上第 0 位固定为 0。
  • 读指令时自动增加。

CPUx 能处理三种大小的数据：字节（8 位）、字（16 位）和 20 位数据；TI 的汇编分别用后缀 .B、.W、.A 表示。数据比 20 位短时，放在寄存器的低位部分，高位清零。看一个寄存器在三种写入下怎样变化：

寄存器和内存之间传 20 位数据：寄存器 → 内存时用 2 个字，低 16 位放在 Memory，第 19–16 位放在 Memory+2 的最低 4 位，Memory+2 其余的位（即第 20–31 位）写 0（§5 的最后一步）；内存 → 寄存器时，Memory+2 里没用到的高位直接忽略。

R0 = PC、R1 = SP、R2 = SR（兼常数发生器）、R3 = 常数发生器，R4–R15 通用。除 SR（16 位）外都是 20 位；写字节清掉 19–8 位，写字清掉 19–16 位。PC 永远是偶数。

§7状态寄存器 SR M11.9

CPU 做完一次加法，怎么知道结果是 0、是负数，还是溢出了？Registro de estado R2 (SR).

registro de estado (ES) / status register (EN)——状态寄存器 SR 是 16 位的。它的位有三种作用：反映运算结果（标志位）、控制低功耗模式（打开 / 关闭内部时钟部件）、打开 / 关闭中断（GIE）。点一位看它的含义：

15–9 · reservado

保留位，不用。不要往 SR 里写 20 位的值，否则行为不可预测。

8 · V · overflow（溢出）

有符号运算的结果超出了目标能表示的范围。具体规则：加法里"正 + 正 = 负"或"负 + 负 = 正"时置 1；减法 / 比较里"正 − 负 = 负"或"负 − 正 = 正"时置 1；其他情况清零。

7 · SCG1 · system clock generator 1

和 SCG0 一起，控制时钟系统里除晶体振荡器和主时钟之外的各个部件的开关，会影响依赖这些时钟的外设。例如：DCO 的偏置开关（具体作用随器件而定）。细节在 M24、M26。

6 · SCG0 · system clock generator 0

和 SCG1 一起控制时钟系统的部件。例如：FLL 的开关（具体作用随器件而定）。细节在 M24、M26。

5 · OSCOFF · oscillator off

置 1 时关闭晶体振荡器（对应 LPM4 模式）。更精确地说：在 LFXT1 没被 MCLK 或 SMCLK 使用时，把它关掉。

4 · CPUOFF · CPU off

置 1 时关掉 CPU——实际上关的是驱动它的主时钟 MCLK。任何一种低功耗模式都会把它置 1。CPUOFF、OSCOFF、SCG0、SCG1 这四位一起请求系统进入某个低功耗模式（M26）。

3 · GIE · general interrupt enable

为 1 时允许可屏蔽中断；为 0 时所有可屏蔽中断都被挡住。进入 RTI 时硬件会自动把它清零（M21）。

2 · N · negativo

运算结果为负时置 1，为正时清零。

1 · Z · zero

运算结果为 0 时置 1，否则清零。

0 · C · carry

运算产生了进位（carry）或借位（borrow）时置 1。

三个 16 位加法的例子，看四个标志位怎样各自独立地变化：

ADD（16 位）结果CZNV
0x7FFF + 0x00010x80000011
0xFFFF + 0x00010x00001100
0x8000 + 0x80000x00001101

第一行：按有符号数是 32767 + 1，正 + 正 却得到负数（第 15 位为 1）→ V = 1，但没有超出 16 位 → C = 0。第二行：按无符号数 65535 + 1 溢出 16 位 → C = 1，结果为 0 → Z = 1；按有符号数是 −1 + 1 = 0，没有溢出 → V = 0。第三行：负 + 负 得到 0（不是负数）→ V = 1，同时有进位 → C = 1。

SR 用了几位

注意：有些资料正文说 SR 只用最低 8 位，但它自己的位图和 TI 手册都把 V 放在第 8 位，第 0–8 位都有定义。按位图记。

第 0–8 位依次是 C、Z、N、GIE、CPUOFF、OSCOFF、SCG0、SCG1、V，第 9–15 位保留。这 9 位都是 rw-0：可读可写，复位后为 0。修改 SR 最好只用 MOV、BIS、BIC 指令。

常数发生器 R2 和 R3

generador de constantes (ES) / constant generator (EN)——常数发生器：R2 和 R3 能产生最常用的 6 个常数 2、4、8、0、1、−1，代码里不必明写出来。好处是代码更短、执行更快，对程序员透明；它还让一批"模拟指令"（instrucciones emuladas）可以用基本指令实现。

细节

有些资料的说法是：R2 的一个字节是 SR，另一个字节用来生成常数。实际机制看寻址方式：

常数由源操作数的寻址方式 As 选出来：R2 在寄存器方式（As = 00）下就是 SR；As = 10 → +4，As = 11 → +8；R3 的 As = 00 → 0，01 → +1，10 → +2，11 → −1（FFh / FFFFh / FFFFFh）。汇编器遇到这 6 个立即数时自动使用常数发生器，不需要额外的代码字。MSP430 的 RISC 指令集只有 27 条指令，靠常数发生器又多出 24 条模拟指令，例如 CLR dst 实际是 MOV #0, dst（#0 由 R3 产生），INC dst 实际是 ADD #1, dst。

SR（R2）的第 0–8 位：C、Z、N 是结果标志，GIE 是中断总开关，CPUOFF、OSCOFF、SCG0、SCG1 控制低功耗模式，V 是有符号溢出。R2、R3 还兼作常数发生器，免费提供 2、4、8、0、1、−1。

§8栈 M11.10

调用一个子程序，CPU 怎么记得要回到哪里？La pila y el puntero de pila R1 (SP).

pila (ES) / stack (EN)——栈，是内存里专门划出来的一块（放在 RAM 里）。CPU 用它自动保存：调用子程序时的返回地址（PC），以及处理中断时的返回地址 PC 和状态寄存器 SR（M21）。程序还可以用它传参数、存临时变量、切换上下文。

栈是一种 LIFO（Last In First Out，后进先出）的数据结构：任何时候只能访问最上面那一项，即 TOS（Top Of Stack，栈顶）。有两个基本操作：PUSH（压入新数据）和 POP（取出最后的数据）。栈指针 SP 指向栈顶，也就是最后存入的那个数据的地址。

PUSH：SP ← SP − 2，@SP ← src　　POP：dst ← @SP，SP ← SP + 2

PUSH 先减后存（predecremento），POP 先取后加（postincremento）。PUSH 的源（origen）和 POP 的目的（destino）都可以是寄存器，也可以是内存。PUSHX.A 压 20 位值时 SP 减 4。

记住四点

  • 栈向低地址增长：压入时 SP 减小，取出时 SP 增大。
  • SP 永远是偶数：栈里可能放字节、字或 20 位数据；即使只压一个字节，SP 也移动 2。
  • SP 指向最后存入的数据（TOS）。
  • 使用前必须给 SP 一个初值：栈的基址。

和 M21 的联系

中断发生时，CPU 自动把 PC 和 SR 压栈，SP 共减 4；RETI 再把它们弹回来。CPUx 用 SR 里空着的高 4 位装下 PC 的第 19–16 位。这一切都靠这里讲的同一个栈。

栈是 RAM 里一块后进先出的区域，SP（R1）指向栈顶。PUSH：SP − 2 再存；POP：先取再 SP + 2。栈向低地址增长，SP 永远是偶数。

自测 12 题

根据本章内容编写的练习题。每题只能点一次，答完会显示解析。

01下面哪一项最能说明一个器件是微处理器，而不是微控制器？

B。CPU、存储器、外设、总线两者都有；MMU 把内存虚拟化，使完整 SO 成为可能，是典型的分界（§0）。

02关于 Von Neumann 架构，哪一句是对的？

C。A、B、D 说的都是 Harvard。MSP430 是 Von Neumann（§3）。

03按字节寻址，地址总线 16 位，最多能寻址多少？

B。216 = 65 536 个地址 × 1 B = 64 KB。1 MB 是 20 位的 CPUx（§3）。

04F5529 能寻址 1 MB，为什么外设、RAM 和中断向量表都放在最低的 64 KB？

B。为了兼容，外设、校准信息、RAM 和一部分 Flash 集中在最低的 64 KB；向量表也在 64 KB 的最顶端（§4）。Flash 本身就从 0x4400 开始，A 不对。

05F5529 的 RAM（含 USB 扇区）占哪段地址？

C。10 KB = 5 个 2 KB 扇区，最低的给 USB。A 是外设，B 是 BSL，D 是 Flash（§4）。

06地址 0xFF90 落在哪个区域？

D。向量表在低 64 KB 的最顶端 0xFF80–0xFFFF，物理上属于 Flash（§4）。

07关于 FRAM，哪一句是对的？

B。C 说的是 Flash；FRAM 的读出不破坏数据。它的短板是速度，不适合高速处理器（§2）。

08字 0x5D19 存在地址 0x2C10。地址 0x2C11 里的字节是？

B。Little endian：LSB 0x19 在偶地址 0x2C10，MSB 0x5D 在下一个奇地址 0x2C11（§5）。

09下面哪个地址可以作为一个字（16 位）的起始地址？

C。字只能在偶地址访问；字节才可以在任意地址（§5）。

10R6 = 0x4A2C1，执行 MOV.B #0x7F, R6 之后 R6 = ?

B。写字节时，数据进第 7–0 位，第 19–8 位全部清零（§6）。

11SR 的 V 位（第 8 位）表示什么？

B。A 是 Z（第 1 位），C 是 C（第 0 位），D 是 GIE（第 3 位）（§7）。

12SP = 0x4400。依次执行 PUSH R5（R5 = 0x1111）、PUSH R6（R6 = 0x2222）、POP R7。之后 SP 和 R7 是？

A。两次 PUSH：SP → 0x43FE → 0x43FC；POP 取出最后压入的 0x2222（LIFO），SP 加 2 → 0x43FE（§8）。
