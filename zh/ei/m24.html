§1室外与室内：有哪些定位技术 2.4.1

localización (ES) / localization, positioning (EN)——定位：指能无线地确定物体或人位置的定位系统。按场景分两类，这就是目标 2.4.1 的答案：

a) Exteriores · outdoors

卫星，或移动网络

  • vía satélite：GPS、Galileo
  • a través de redes móviles（运营商的蜂窝网络）
b) Interiores · indoors

技术很多，没有统一方案

主要有 10 类：BTLE · Wi-Fi · MEMS · Zigbee · Infrarrojos (IR) y ultrasonidos · GPS Pseudolites · Femtocells · RFID · UWB · LED

加粗的 6 种是目标 2.4.3 要比较的。

补充（了解即可）：墙上多出来的 HAIP，通常指 HAIP (High Accuracy Indoor Positioning)——高精度室内定位，Nokia 提出的一种基于 Bluetooth Low Energy、用天线阵列测到达角 (AoA) 的方案，思路和 §5 的 Bluetooth 5.1 direction finding 相近。

为什么室内要另找办法

我们大部分时间都在室内（据分析师估计，约 90%），但室内没有一个像 GPS 或运营商网络那样、能覆盖所有区域和所有用例的 solución global。选哪种室内方案并不容易。

同样叫“定位”，精度差别很大。可以用三个同心圆概括这件事：

Low accuracy · 5–20 m · 卫星定位

GPS 大约能做到 5–20 米的精度，取决于信号条件。开车找一栋楼够用；要找到商店里的某个货架、博物馆里的某幅画，就不够了。

到了室内更糟：卫星信号被建筑挡住，GPS 无法保证正常工作（了解即可）。

Proximity · 1–10 m · Wi-Fi / Bluetooth

今天基于 RSSI (Received Signal Strength Indication)——接收信号强度的 Bluetooth 和 Wi-Fi 系统，精度足以判断一个物体或人是否在几米之内，也就是 proximidad 级别。

局限：接收端只知道发射端在某个圆形区域里，不知道信号从哪个方向来。

Positioning · < 1 m · micro-localización

下一代技术的目标是亚米级、直到几厘米，叫 micro-localización (ES) / micro-location (EN)——微定位。用例：免接触门禁（hands-free access control）、资产追踪等。

本章讨论三种：Bluetooth 5.1、UWB（IEEE 802.15.4z）、Wi-Fi 802.11az。§5 详细讲。

记忆法：室外 = 天上的卫星 + 地面的基站；室内 = 无线电类（BTLE、Wi-Fi、Zigbee、RFID、UWB、Femtocells、Pseudolites）+ 非无线电类（MEMS 惯性传感器、红外、超声波、LED 光）。其中 GPS Pseudolites（室内的“虚拟卫星”）和 Femtocells（运营商的小基站）可以看作把室外思路搬进室内。

§2三类方案：RTLS、proximidad、analítica 2.4.2

部署室内定位，第一个决定是方案类型，由用例决定：有的应用要实时、连续的定位（比如室内导航）；有的只要在几个关键点检测到“有人在”（安防、配送）；还有的只分析用户位置的历史记录（比如营销）。据此分成三类：

定义 · 2.4.2 · RTLS

RTLS (Real Time Location System)——实时定位系统，也叫 IPS (Indoor Positioning System)——室内定位系统：能在室内空间的任意一点、实时定位。一般需要部署传感器网络（WSN）；精度要求不高时，也有方案能免去这一步。

定义 · 2.4.2 · Proximidad

soluciones de proximidad (ES) / proximity solutions (EN)——邻近（近场）方案：传感器网络只覆盖某些感兴趣的区域，所以只有在某个传感器的覆盖范围内才知道位置。它实现 geo-fencing——地理围栏逻辑：划定一个 micro-área，在其中向外部系统或用户产生事件或内容。与 IPS 不同，它不需要检测 outdoor ↔ indoor 的过渡。

第三类是 soluciones analíticas——分析型方案：匿名采集传感器周围检测到的用户信息，和 Business Intelligence 工具结合，把位置和核心业务数据放在一起用。例如商场营销、按“曝光次数”拍卖广告位。

切换看看：同一栋楼，三类方案各知道些什么。

§4位置是怎么算出来的 2.4.3

定位分两层：先测量（Algoritmos de localización），再用测量值算位置（Técnicas de localización）。三种基本测量：

测时间

TOA / TDOA

Time (Difference) of Arrival——到达时间（差）：用发射和接收的时间差，算出传感器与终端之间的距离。

测角度

AOA

Angle of Arrival——到达角：信号到达的角度，可以从传感器看，也可以从终端看。需要视线。

测功率

RSSI

用接收到的信号功率估计距离。最简单、最经济的选项。

有了测量，用哪种技术算位置？先看中间一列自己猜，再点击右列揭晓它依赖什么：

Técnica怎么做依赖什么（点击揭晓）
SignPost把离终端最近的传感器的位置当作终端的位置简单的 RSSI
Triangulación用信号的方向（角度）求位置AOA；要用一个以上的传感器，或天线阵列
Trilateración用到各传感器的距离求位置距离估计，不需要天线阵列；通常用 RSSI（用 ToA 的话，网络要同步）

Fingerprint 的两个阶段（了解即可）：离线阶段做 site survey，生成 radio map；在线阶段把测得的值和 radio map 匹配。缺点是建库费时费力，环境一变还要更新。§6 的 client based 架构用的就是这种数据库。

动手试试 trilateración：三个位置已知的传感器（anchors）各测出一个到终端的距离，每个距离画一个圆，三个圆的交点就是位置。测距有误差时，三个圆不会交于一点，就用最小二乘求一个最接近的点（最小二乘这部分了解即可；按上面的表，trilateración 通常基于 RSSI 测距）。

误差档位是示意值：RSSI 受 multipath 影响大，取 ±2 m；UWB 取 ±0.1 m，对应 §5 的约 10 cm。解法是线性化最小二乘（LLS）：三个圆方程两两相减，消去 x² 和 y²，得到两条直线再联立。

根本问题：multipath

所有这些技术都在用手头的数据尽量提高精度，也都要对付同一个根本问题：efecto multipath (ES) / multipath effect (EN)——多径效应，即信号在物体上发生反射、折射、衍射和散射。§5 的新技术都在这一点上下了功夫。

§5下一代：micro-localización 2.4.3

下面比较三种把精度推到亚米级的技术。共同点：不再只靠 RSSI，而是测角度或时间。

Bluetooth 5.1 · 2019

测角度：AoA / AoD

以前的 Bluetooth 靠 RSSI，只知道“在某个圆里”。5.1 加入 direction finding，用 AoA（到达角）或 AoD（离开角）：数据包后附一段 CTE (constant tone extension)——恒定音调扩展；接收端用至少 2 根天线的阵列，根据相位差、波长和天线间距算出入射角。再配合 RSSI，并部署多个 locator 做 trilateración。

亚米级，直到几十厘米。

UWB · IEEE 802.15.4z

测时间：ToF

不用信号强度，而用 ToF (Time of Flight)——飞行时间：射频信号以光速传播，与环境无关，所以比 RSSI 稳健。它发的是纳秒量级的脉冲串，不是调制的正弦波，更不怕 multipath。还可以加天线阵列测角度。

约 10 cm，三者中最准（厘米级）。

Wi-Fi 802.11az · NGP

测往返时间：FTM / RTT

Next Generation Positioning 建立在 FTM (Fine Timing Measurement)——精细时间测量上：用 ToD（离开时间）和 ToA（到达时间）时间戳算 RTT（往返时间）。借 Wi-Fi 6 / 7 更宽的信道（160 / 320 MHz）提高分辨率，用 MIMO 抗 multipath。

测试数据：视距和非视距下都能到分米级。

除了精度，还要看安全、功耗、成本、已有基础设施、覆盖距离和互操作性；环境、系统设计、天线路径延迟等都会让实际精度低于标称值。UWB 有一个产业联盟 FiRa Consortium（了解即可）。

计算器：UWB 的 ToF 怎么测？tag 和 anchor 各记两个时间戳，见下图。改动时间戳，看距离怎么变。

默认数值只作演示：ToF = 20 ns，约 6 m。T1、T2 由 anchor 用自己的时钟记，T0、T3 由 tag 用自己的时钟记，公式只用各自时钟内部的差值，所以两边时钟不必同步。

Wi-Fi 802.11az 的 FTM 结构相同：手机发出 M1，AP 回 M2，四个时间戳 t1 = ToD(M1)、t2 = ToA(M1)、t3 = ToD(M2)、t4 = ToA(M2)，于是 ToF = [(t4 − t1) − (t3 − t2)] / 2，距离 = 光速 × ToF。

§6两种架构：server based 与 client based 2.4.4

不管用已有基础设施，还是加装传感器（自有的或第三方的），常见架构都可以归为两类。区别在于：谁发信号、谁接收、谁算位置。

定义 · 2.4.4
  • Server based / Network based——基于服务器（网络端）的架构：终端周期性地发信号，传感器接收并转给服务器，由服务器算位置。终端上不用装任何东西。
  • Client based / Mobile based——基于客户端（终端）的架构：传感器发信号，终端接收，借助辅助数据库自己算位置。位置只有终端知道。

逐步看数据怎么流：注意两条泳道的箭头方向相反。

概览

记忆法：谁算位置，就叫什么 based。服务器算 → server based；终端（客户端）算 → client based。

对比Server / Network basedClient / Mobile based
谁发无线信号终端，周期性发送，带唯一标识（MAC address）传感器
谁接收一个或多个传感器终端

终端上要装什么什么都不用装定位模块
给开发者的接口服务器提供 API，查询指定终端的位置供应商提供 SDK，把 LBS 服务和终端上的定位模块集成起来
通信传感器到服务器走 Wi-Fi 或运营商蜂窝网终端直接接收传感器发出的信号
隐私—位置只有终端知道，被认为满足隐私要求；某些用例仍要把位置发给服务器
典型做法Wi-Fi、BTLE、Zigbee；主要用于分析型方案，也用于 IPS 和 presencia用终端自带的 MEMS 传感器，加上多种无线信号（Wi-Fi、BTLE……），组成混合技术

概括起来：公共场所的系统，倾向于把智能手机发出的标准信号当作 beacon，由 WSN 接收、在中央服务器处理；出于隐私，基于终端的定位结果只留给机主，特定情况下再请他同意共享。私人或工业系统则常给员工和访客配 tags 或手环。

归类：下面每句话说的是哪种架构？先想，再点开看答案。

Server / Network based

终端只是照常发出无线信号，计算全在服务器上，所以不需要在终端上安装任何东西。

Client / Mobile based

定位模块驻留在终端上，供应商提供 SDK，把 LBS 服务和这个模块集成起来。

Server / Network based

位置在服务器上，app 通过服务器提供的 API 查询指定终端的位置。

Client / Mobile based

供应商利用终端自带的 MEMS 传感器，和 Wi-Fi、BTLE 等多种无线信号组成混合技术。

Client / Mobile based

位置只由用户自己的终端算出、只有它知道，所以被认为满足隐私要求。不过某些用例仍需把位置发给服务器。

别混淆：还有另一种分法（了解即可）：device-based（目标带着无线设备，例如手机）和 device-free（目标什么都不带，靠环境里的无线设施分析它对信号的影响）。那是“目标带不带设备”的区别，不是本节“谁算位置”的区别。

§7选 RTLS 时要考虑什么 了解即可

选 RTLS 时要考虑下面这些因素。它们往往反过来决定了前面三个选择（方案、技术、架构）。

Precisión

精度

最基本的因素，按用例定：< 2 m、3–5 m、房间 / 区域级。先问：proximidad 够不够？

Dispositivos

终端

尽量选多数终端都支持的技术，即智能手机支持的。某些用例可以用 tags 或手环：不需要屏幕和键盘，通常带可编程按钮。

Integración

集成

与外部系统、移动应用的集成：评估现有的 API / SDK、架构，以及 pull / push 管理机制。

Instalación

安装

部署 WSN 时：传感器选址，物理安装（供电、布线、与服务器通信），需要的话还要校准，并事先测试。

自测 12 题

根据本章内容编写的练习题。每题只能点一次，答完会显示解析。

01下面哪一项属于室外定位技术？

C。室外靠卫星（GPS、Galileo）或移动网络。其余三种都在室内技术的列表里（§1）。

02“传感器网络只覆盖若干感兴趣的区域，只有在传感器覆盖范围内才知道位置。”这说的是？

A。这是 proximidad 方案的定义。RTLS / IPS 能在室内任意一点实时定位（§2）。

03关于 RTLS / IPS 和 proximidad，哪一项正确？

D。与 IPS 不同，proximidad 不需要检测 outdoor / indoor 过渡；geo-fencing 是 proximidad 的逻辑（§2）。

04哪种技术精度不错，但需要视线、范围只有几米，更适合检测存在和运动？

B。Infrarrojos 需要 línea de vista，范围只有几米；它和超声波一般被看作辅助技术（§3）。

05按 §3 表中 2014 年时的情况，哪种技术非常准（约 30 cm），但成本很高，信号衰减严重、功耗高？

A。UWB。注意到 2021 年，它的精度是约 10 cm（§3、§5）。BTLE 和 Zigbee 的卖点恰恰是低功耗。

06哪种技术单独使用时，原则上不需要专门部署 WSN 基础设施？

C。用加速度计、磁罗盘、陀螺仪、气压计定位，IndoorAtlas、Navisens、Movea 就这样做（§3）。

07Wi-Fi 室内定位的主要弱点之一是？

D。Wi-Fi 在 AP 和手机里最普及，但 alto consumo de la batería 是弱点；而且一般要加装 AP 才够精度（§3）。

08UWB 用什么估计距离，因而比 Bluetooth 的 RSSI 法更不受环境影响？

B。射频信号以光速传播、与环境无关，所以基于 ToF 的距离估计比 RSSI 更稳健（§5）。

09“终端周期性发出带 MAC 地址的信号，传感器收到后连同 Id_sensor、RSSI 发给服务器。”这是哪种架构？

A。位置在服务器上算，终端上不用装任何东西。Proximidad 是方案类型，fingerprint 是定位技术，都不是架构（§6）。

10关于 Client / Mobile based 架构，哪一项正确？

C。供应商提供 SDK，位置只有终端知道。A、B 是 server based 的特点（§6）。

11RFID 主要用在哪里？

B。RFID 非常普及、成熟，但被认为不太适合 RTLS。C 是 femtocells，D 是 LED（§3）。

12按 §4 的表，trilateración 的特点是？

D。A 是 triangulación，B 是 fingerprint，C 是 SignPost（§4）。
