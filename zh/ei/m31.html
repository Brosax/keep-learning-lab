§1什么是 IA：四种定义 3.1.1

先说 inteligencia (ES) / intelligence (EN)——智能。这个词来自拉丁语 intellegere：inter（之间）+ legere（读、挑选），意思是理解、感知。它指理解、吸收、加工信息并用来解决问题的能力。智能不止一种，这是 Howard Gardner 的多元智能观点：一个人可以是国际象棋冠军，却在别的事上很笨拙。

定义 · 3.1.1

IA 是机器的智能，也是计算机科学中研究如何让信息系统拥有这种智能的分支。它的目标很宏大：造出一台会思考的机器，它有智能、有意识、能学习、有自由意志，还合乎伦理。这个名字由 John McCarthy 在 1956 年提出。

IA 的定义很多。八条经典定义可以排进一张二维表：

  • 上下：pensar vs actuar。上面两格关注思维过程和推理，下面两格关注行为。
  • 左右：humanamente vs racionalmente。左边以“像不像人”衡量成功；右边和一个理想的标准比较，即 racionalidad——理性：一个系统如果在已有知识下“hace lo correcto”（做正确的事），它就是理性的。

点一点：四个格子各对应一种研究路线。点开每一格，看代表定义（中文意译）和这条路线的做法。

Pensar humanamente · 像人一样思考

代表定义（意译）：Haugeland (1985)：让计算机真正“思考”，造出字面意义上有心智的机器。Hellman (1978)：把我们和人类思维联系在一起的活动（决策、解题、学习……）自动化。

路线：modelado cognitivo——认知建模。先弄清人是怎么想的，有三种办法：introspección（内省，捕捉自己的想法）、experimentos psicológicos（观察人的行为）、imágenes cerebrales（观察大脑活动）。有了足够精确的心智理论，就把它写成程序；程序的行为若和人一致，说明其中一些机制可能和人相同。

例：Newell 和 Simon 的 GPS（General Problem Solver）。他们不满足于程序解对题，更想比较 GPS 的步骤和人解同一道题的步骤。由此发展出 ciencia cognitiva（认知科学）。

Pensar racionalmente · 理性地思考

代表定义（意译）：Charniak 和 McDermott (1985)：用计算模型研究智力。Winston (1992)：研究让感知、推理和行动成为可能的计算。

路线：leyes del pensamiento——思维法则。亚里士多德的 silogismos（三段论）给出了“前提正确则结论必然正确”的论证模式（苏格拉底是人；人都会死；所以苏格拉底会死），由此诞生了逻辑学。IA 的 tradición lógica（逻辑传统）希望在这类逻辑程序上搭建智能系统。

两大障碍：① 把非正式、又不是百分之百确定的知识写成形式化的逻辑并不容易；② “原则上能解”和“实际上解得出”差距很大，几百条事实就可能耗尽计算资源。

Actuar humanamente · 像人一样行动

代表定义（意译）：Kurzweil (1990)：创造机器的艺术，这些机器执行的功能如果由人来做就需要智能。Rich 和 Knight (1991)：研究如何让计算机做那些目前人做得更好的事。

路线：Test de Turing。不问机器“怎么想”，只看它的行为能不能和人区分开。详见 §3。

Actuar racionalmente · 理性地行动

代表定义（意译）：Poole et al. (1998)：inteligencia computacional 研究的是智能 agente 的设计。Nilsson (1998)：IA 关心人工制品中的智能行为。

路线：agente racional——理性智能体。它的行动能得到最好的结果；有不确定性时，得到最好的期望结果。正确推理只是理性的一种手段：有时根本没有“正确”选项也得行动；有时不推理反而更好，比如手碰到烫的东西立刻缩回，这个反射比深思熟虑更有效。

两个优点：① 比“思维法则”更通用，因为正确推理只是实现理性的众多机制之一；② 比基于人类行为或思维的路线更便于科学研究，因为理性的标准在数学上定义得很清楚。

在复杂环境里，完美的理性（永远做对）算力上做不到。实际做法是先假设完美理性来定义问题，再采用 racionalidad acotada（有限理性）：资源不够时也能恰当地行动。本章 §5–§7 的 agentes 就属于这条路线。

以人为中心的路线部分是经验科学（观察、假设人的行为）；理性路线结合了数学和工程。四条路线历史上都有人走，现在两派常常合作。

§2IA fuerte 与 IA débil 3.1.2

IA débil

弱 IA · weak AI

猜想：机器可以被编程，表现出智能行为。IA 界普遍接受。

IA fuerte

强 IA · strong AI

猜想：机器经过编程后真正拥有智能，有意识。争议很大。

定义 · 3.1.2

区别在于“表现出智能”还是“拥有智能和意识”。难点在于，智能和意识是内部特征，没法直接观察。Turing 的看法是：我们说别人聪明，是因为他们表现得聪明，尽管我们看不到他们的内心状态。那么，一台表现出同样外部特征的机器，我们愿不愿意给它同样的待遇？

先想再点：下面每句话说的是哪一种？点击右列揭晓。

说法属于（点击揭晓）
IA 界普遍接受的猜想IA débil
反对者：机器本质上不同于人，永远不会有感情、分辨善恶、反思自身IA fuerte（反对它的论点）
支持者：人的心智由本身既非人类、也无意识的部件组成，组合起来却有了意识，机器为什么不能？IA fuerte（支持它的论点）
RNA、algoritmos genéticos、sistemas expertos 都是实现它的常用方法IA débil
最难验证，因为智能和意识无法直接识别IA fuerte

也有研究者认为 IA 的目标不可能或不自洽（Hubert Dreyfus、John Searle），Joseph Weizenbaum（ELIZA 的作者）则认为 IA 不合伦理。

§3Test de Turing 3.1.3

定义 · 3.1.3

Test de Turing (ES) / Turing test (EN)——图灵测试：Alan Turing 1950 年提出，目的是给智能一个令人满意的操作性定义（definición operacional）。一个人类审问者用书面形式提出若干问题后，如果无法判断书面回答来自人还是计算机，这台计算机就通过了测试。

概览

要通过测试，计算机需要四种能力；Total Turing Test 再加两种。这六门学科构成了 IA 的大部分：

Test de Turing

4 种能力

  • procesamiento de lenguaje natural：流利地交流
  • representación del conocimiento：存储知道或学到的东西
  • razonamiento automático：用存储的信息回答问题、得出新结论
  • machine learning：适应新情况，发现并外推模式
Total Turing Test

+ 2 种能力

  • visión por computadora：识别物体（因为加了视频信号）
  • robótica：操作物体（因为要通过小窗口递送实物）
为什么不要身体

故意避开物理接触

标准测试刻意避免审问者和计算机直接物理接触，因为模拟人的身体对智能来说不是必需的。

如今 IA 不太花力气去通过 Turing 测试，更看重研究智能的基本原理，而不是复制一个现有的智能。CAPTCHA（Completely Automated Public Turing test to tell Computers and Humans Apart）也来自这个想法。

§4IA 的主要技术 3.1.4

下面这些都是写出“符合 IA débil 的程序”的常用办法。先认识一个相关的概念：inteligencia computacional——计算智能：IA 的一个分支，研究让复杂、多变的系统表现出智能行为的自适应机制，主要技术是 RNA、algoritmos genéticos 和 lógica borrosa。下面这张组合图给三种技术各画了一个例子：

先理清包含关系

machine learning 是 IA 的一种方法 → 其中最流行的技术是 RNA → deep learning 是 RNA 层数很多的 machine learning → IA generativa 是会生成内容的 deep learning 模型。sistemas expertos 和 algoritmos genéticos 则是另外的路线：前者靠专家写的规则，后者靠模拟进化。

点开每一种技术：

sistema experto (ES) / expert system (EN)——专家系统

一个计算机系统，装着一位或多位人类专家在某个具体主题上的知识。它由专家提供的一组 reglas（规则）构成，好坏很大程度取决于规则的质量；它能从已知事实推理出结论，并推荐最合适的行动。知识的存储和解题策略是两件分开的事。

Componente作用
Base de conocimiento由该领域专家建立；系统的水平取决于专家提供的知识
Medio de comunicación用户和系统对话：提问、得到回答（或反过来）
Ayuda sensitiva al contexto通常每个界面都有，按用户当前所处位置给出帮助
Componente de solución de problemas分析问题，用 motor de inferencia（推理引擎）推出合适的行动方案；推理引擎在用户和知识库规则之间交互

推理引擎由多条 reglas de inferencia 组成；增删一条规则不影响其他规则，就像人更新知识一样。两种推理方式：hacia adelante（正向：从已有数据出发，用规则不断得出结论，直到目标）和 hacia atrás（反向：从一组目标出发往回推，看现有数据能不能达成其中某个目标）。

例：Dendral（Stanford，60 年代中期，辅助识别未知有机化合物）；Mycin（Stanford，70 年代，诊断血液感染并推荐抗生素，诊断正确率约 65%，好于多数非专科医生，低于专家的 80%；但出于法律和伦理原因从未投入使用：诊断错了谁负责？）。

algoritmo genético (ES) / genetic algorithm (EN)——遗传算法

有些问题太复杂，直接求解会耗尽内存或算不完。遗传算法让一代代试验解“进化”：随机行为 + 繁殖理论 + 自然选择。

  1. 随机生成一组试验解。每个解叫 cromosoma（染色体），它的每个组成部分叫 gen（基因）。
  2. 随机挑选 padres（父母），但看起来更可能通向解的染色体被选中的概率更大，即“适者生存”。判断哪些染色体最好，是整个算法最难的一步。
  3. 每个后代（descendencia）是父母基因的随机组合，还可能发生 mutación（突变）。
  4. 重复很多代，解越来越好，直到足够好为止。

上面组合图的第三幅把这个过程画成一个循环：población inicial / nueva generación（初始种群／新一代）→ evaluación（评估：每个个体按它的“基因”打分，图里 ★ = 5、▲ = 4、● = 3、■ = 2）→ selección（选择：留下的多是高分的 ★ 和 ▲）→ cruzamiento / mutación（交叉／突变：后代的符号是父母符号的拼合）→ sustitución de población（替换种群）→ 回到新一代。

它不保证一定能找到解，但对相当多的复杂问题很有效。用在程序开发上叫 programación evolutiva（进化编程）：让程序进化出来，而不是写出来。

Red Neuronal Artificial, RNA (ES) / Artificial Neural Network, ANN (EN)——人工神经网络

一组互相连接的处理单元（nodos 或 neuronas），协同产生一个输出，用来模拟生物神经网络（例如大脑）的某些特性。

  • 每个连接有一个 peso（权重），表示它的影响力；神经元取输入的加权和，再用一个函数决定输出。网络通过改变权重来学习。
  • 处理是并行的，不是串行的；有 tolerancia a fallas（容错）：部分神经元失效也能继续工作。
  • 能从一组例子里学会解复杂问题，并泛化去解没见过的问题。
  • 没有按顺序执行指令的中央处理器，架构和 von Neumann 模型很不一样。

RNA 由若干层互联的节点组成，每个连接的权重可以通过 machine learning 调整。上面组合图的第一幅是一个给动物图片分类的网络：input layer 4 个神经元 → hidden layer 1 有 5 个 → hidden layer 2 有 3 个 → output 1 个，输出标签 “DOG”；相邻两层的神经元两两相连。§8 里你可以亲手算。

aprendizaje automático (ES) / machine learning (EN)——机器学习

机器从数据中学习，随经验改进，不需要显式编程。算法很多（regresión lineal 和 logística、árboles de decisión、bosques aleatorios、SVM、KNN、clustering、RNA 等，各适合不同问题），其中最流行的是 RNA。

学习方式靠什么学
aprendizaje supervisado（监督）例子：带标签的数据，告诉网络某些输入应该得到什么输出
aprendizaje por refuerzo（强化）奖励和惩罚
aprendizaje no supervisado（无监督）关联
aprendizaje auto-supervisado（自监督）混合技术

用途：clasificar patrones（模式分类）、预测一个序列的值（regresión，回归）、agrupamiento（clustering，聚类）等。

aprendizaje profundo (ES) / deep learning (EN)——深度学习

machine learning 的进化：RNA 有很多层，学习往往是 auto-supervisado，因此能从海量非结构化、未标注的数据里提取含义和关系。

  • 基本 machine learning 的 RNA：3 或 4 层（1 个输入层、1 个输出层、1–2 个隐藏层）。
  • deep learning 的 RNA：可以有几百个隐藏层。

训练时权重要在网络里前后传播，计算量很大；部署时只向前传播，所以能高效地跑在小型、可部署的硬件上。逐层抽象的例子见下面的人脸和汽车两例。

lógica borrosa / difusa (ES) / fuzzy logic (EN)——模糊逻辑

它和 RNA、algoritmos genéticos 并列为 inteligencia computacional 的主要技术：在决策中处理不确定性和不精确性。它不在 3.1.4 的列表里。

§5Agente inteligente 3.1.5

定义 · 3.1.5

agente (ES) / agent (EN)——智能体（拉丁语 agere，“做”）：凡是通过 sensores（传感器）感知自己的 ambiente（环境），并通过 actuadores（执行器）在这个环境中作出响应的东西，都是 agente。

agente 是 inteligente 的，如果它总是做正确的事，即做能让它获得最佳 desempeño（表现）的事。

Agente de software

软件智能体

一个和其他（子）程序交互的（子）程序；它的感知和动作都是编码后的比特串。“智能”的软件 agente 是一个自主实体，它感知并作用于环境，引导自己的活动去实现目标。

Desempeño

怎么衡量“做对”

要有一个客观的表现度量，没有一把尺子能通用于所有 agente。这个度量由一个 autoridad（权威方）提出，规定什么样的表现算令人满意。

Agente racional ideal

理想理性智能体

对每一种可能的感知序列，都做能让表现度量最大化的动作，依据是感知序列提供的证据和它内置的知识。

Mapeo de percepciones a acciones · 感知到动作的映射

agente 的行为只取决于它到目前为止的感知序列，所以原则上可以列一张表：每种感知序列对应什么动作。但这张表通常大得存不下，甚至是无限的。设计理想 agente，就是规定每种感知序列该做什么；不用真的列表，可以用一个函数来描述这个映射。实际上，理想理性 agente 做不出来：优化所需的时间太长，即使问题规模很小也是如此。所以要用更简单的 agente，见 §7。

也有人（例如 Russell 和 Norvig）更喜欢用 agente racional 而不是 agente inteligente 这个说法。

§6Agente 的 ambientes 3.1.6

ambiente (ES) / environment (EN)——环境，来自拉丁语 ambiens（环绕）。在科学和工程里，系统是我们研究的那部分宇宙，环境是系统边界以外的其余部分。不论哪种 agente，关系都一样：agente 对环境施加动作，环境向 agente 提供感知。

环境可以按五个维度区分。每一行的左边都是对 agente 更容易的一侧：

维度定义要点为什么左边更简单
accesible / no accesible传感器能获取环境的全部状态，即所有和选择动作相关的方面agente 不必维护内部状态来跟踪环境
determinista / no determinista下一个状态完全由当前状态和 agentes 选择的动作决定不用担心不确定性。注意：不可访问的环境可能看起来是非确定的
episódico / no episódico经验分成一个个 episodio（感知 + 行动）；后面的 episodio 不依赖前面的动作每次只需对付当前这一段*
estático / semidinámico / dinámicoagente 思考时环境会不会变：会变是 dinámico。环境不随时间变、但对表现的评分随时间变，是 semidinámico不必边决策边观察世界，也不用在意时间流逝

§7Agente 的类型 3.1.7

理想理性 agente 做不出来（§5），所以要用三种更简单的 agente。

注意名字：学习目标 3.1.7 叫 reactivo simple、basado en objetivos、basado en utilidad；有的资料叫 reflejo simple、basado en (logro de) metas、basado en el logro del mejor desempeño。考题可能用任意一种。

学习目标 3.1.7另一种叫法靠什么决定动作
reactivo simpleagente de reflejo simple当前感知 + reglas condición-acción（条件-动作规则）
basado en objetivosagente basado en (logro de) metas预测动作的后果，判断是否 deseable（可取／不可取，二值）
basado en utilidadagente basado en el logro del mejor desempeñoutilidad 函数：把一个状态映射成一个实数，表示满意程度

Agente reactivo simple · 简单反射型

完整的理想映射表太大（可能比宇宙里的粒子还多），但很简单的问题可以用 condición-acción 策略：SI percepción = condición_i ENTONCES realizarAcción_i。人也有这种连接：有的是学来的（看到障碍物就刹车），有的是天生的反射（东西靠近眼睛就眨眼）。

算法：estado ← interpretarEntrada(percepción)，acción ← condiciónAcción(estado)，返回 acción。实现可以很高效（例如用 hash 表），但适用范围很有限。

Agente basado en objetivos (metas) · 目标型

只知道当前状态并不总是够用。机器人到了路口，直走、左转还是右转，取决于它想去哪里。所以除了当前状态，它还需要 meta（目标）信息，即哪些情况是可取的。它会考虑未来：“如果做这个动作会怎样？”“那样可取吗？”。有时一个动作就能达到目标，有时要找很长的动作序列；找这类序列正是 búsqueda（搜索）和 planificación（规划）这两个 IA 子领域的任务。

对比反射型：效率较低，但更灵活。只要换一个目的地，就会产生新的行为；反射型的“何时转弯”规则只适用于一个目的地，换目的地就得换规则。

Agente basado en utilidad · 效用型

光有目标还不足以产生“相当好”的行为：很多动作序列都能把机器人带到目的地，但有的更快、更便宜。目标只能把状态分成“可取”和“不可取”两类；更一般的表现度量则能比较不同状态。

如果 agente 更喜欢某个状态，就说这个状态的 utilidad——效用更高。utilidad 是一个函数，把一个状态映射为一个实数，表示满意程度。在两种情况下，它能帮 agente 做出理性决策，而这两种情况单靠目标解决不了：

  1. 目标之间有冲突，只能实现其中一部分（例如速度和安全），utilidad 决定该怎么折中；
  2. 有好几个目标，但没有一个能确定实现，utilidad 用来权衡成功的可能性和各目标的重要性。

有时可以把 utilidad 函数转换成一组目标，这样目标型 agente 的决策和效用型几乎一样。

§8分析一个基本的 RNA 3.1.8

生物神经元通过轴突（axones）连到别的神经元的树突（dendritas），传递的电信号强度可变，所以一个神经元对邻居的影响有大有小。人工神经元把这个“影响力”简化成一个数，即 peso (ES) / weight (EN)——权重。

一个神经元怎么算
  1. 算 entrada efectiva（有效输入，即加权和）：s = v₁·w₁ + v₂·w₂ + v₃·w₃
  2. 和这个神经元的 umbral (ES) / threshold (EN)——阈值 θ 比较；
  3. 输出 0 或 1。

本页按 s ≥ θ → 1，否则 → 0 计算。“和阈值比较”本身没有说相等时怎么办；但下面两个网络只有取“≥”才能正常工作（例如 Red a 最上面那个隐藏神经元，s = 1、θ = 1 时必须输出 1），所以这里取 ≥。

一个 RNA 由几层互联的神经元组成：entrada（输入层）、oculta（隐藏层）、salida（输出层）。分析一个基本 RNA，就是给定输入，逐层算出每个神经元的输出（这就是 inferencia，推理阶段）。训练题 E31 练的正是这一步：它只涉及推理阶段，不涉及训练。

分析步骤
  1. 对每个隐藏神经元：把每个输入乘以对应权重，加起来得到 s；
  2. s 和该神经元的 θ 比较，得到 0 或 1；
  3. 把隐藏层的输出当作输出神经元的输入，重复 1–2；
  4. 对所有输入组合都算一遍，列成真值表，看网络实现了什么函数。

计算器：默认是两个预设网络中的 Red a，输入 [1, 1]。先用 [1, 1] 分别测试 Red a 和 Red b。每个权重和阈值都可以改，结果实时更新。

§9RNA 怎么学 了解即可

看一个例子：一个监督学习的 RNA 给人和动物（狗、猫……）的图片分类，有输入、隐藏、输出三层。输入层放入图像数据（可以是像素），隐藏层有大量系数（权重）需要调整，使输出层给出这张图对应的标签。它有两个阶段：

Entrenamiento

训练

用大量学习样本（图像 + 标签）让网络学会把每张图和它的标签联系起来。学习是自动的迭代过程，最经典的方法是 gradiente descendente（梯度下降）。

Inferencia

推理

学完之后，网络能泛化：正确分类一张从没见过的图，例如分清一张新的人脸和一张狗脸。§8 的计算就是推理。

点一点：下图把两个阶段上下对照。点图里的方框，看每一步在做什么。

Large N · 大量训练样本

训练用非常多的学习样本（图里标作 “Large N”），每个样本是一张图像加上它的标签。图里推理阶段的样本是 “Smaller, varied N”：数量较少、内容多变，而且是网络没见过的。

Forward · 前向传播

图像数据从输入层进入，逐层向前传到输出层，得到网络此刻的“猜测”。图里输入的是一张人脸，网络却输出了 “dog”：训练初期的权重还不对。

=? → error → backward · 比较、误差、反向传播

把输出 “dog” 和这张图的标签 “human face” 比较（=?），两者的差就是 error（误差）。误差向后（backward）传回网络，用来调整权重；最经典的调整方法是 gradiente descendente（见下方）。对每个样本重复 forward → 比较 → backward，网络就逐步学会。

Inference · 推理

学完之后只剩 forward：没有标签、没有比较、没有 backward。新的人脸图像一次前向通过，网络就输出 “human face”，这就是泛化。部署时只向前传播，所以计算量小得多。

Gradiente descendente · 梯度下降

打个比方（见下面雾中下山的插画）：大雾中站在山坡上，只看得见一米远。想下到谷底，就往几个方向各试一步，找出坡最往下的方向，迈一步，重复，直到谷底。

规则：x(n+1) = x(n) − K·F′(x(n))。F′ 是斜率（导数），K 调节步长。斜率为负时 x 增大，斜率为正时 x 减小。看下面 a、b、c、d 那张曲线图：在 a 点斜率为负，往右走一步到 b = a + Δa；在 d 点斜率为正，往左走一步到 c = d − Δd，两种情况都向谷底靠近。K 太大会越过最小值，太小则要走很多步。

用到 RNA 上：定义一个误差函数 E（期望输出和网络输出之差的度量），它取决于权重；用链式法则求 E 对每个权重的导数，再用这条规则更新权重，让 E 趋向最小值 0。

试一试：取函数 F(x) = (x − 2)²，最小值在 x = 2，导数 F′(x) = 2(x − 2)。改一改 K，看看 K = 0.1、0.9、1.1 时有什么不同。

01Winston (1992) 把 IA 定义为“研究让感知、推理和行动成为可能的计算”。它在 §1 的四格表里属于哪一格？

C。§1 的四格表把 Charniak 和 McDermott (1985)、Winston (1992) 放在 Pensar racionalmente 一格。

02按 §5，一个 agente 是：

A。这是 agente 的定义；它是 inteligente 的，如果总是做能获得最佳表现的事（§5，目标 3.1.5）。人、机器人、软件都可以是 agente。

03“机器可以被编程，表现出智能行为”，这个猜想叫什么？

B。IA débil 只要求“表现出”智能，被广泛接受；IA fuerte 要求机器真正拥有智能和意识（§2）。

04为什么 IA fuerte 很难验证？

D。我们说别人聪明，也只是因为他们表现得聪明，看不到他们的内心状态（§2）。

05在 Turing 测试中，计算机在什么情况下算通过？

A。这是 Turing 1950 年给出的智能的操作性定义（§3，目标 3.1.3）。递送物体属于 Total Turing Test。

06和标准 Turing 测试相比，Total Turing Test 额外要求哪两种能力？

C。它加了视频信号和一个递送实物的小窗口，所以要能识别物体、操作物体。A、B 是标准测试本来就需要的四种能力（§3）。

07一个程序由专家提供的规则组成知识库，用 motor de inferencia 正向或反向推理，给出建议。这是哪种技术？

D。sistema experto：base de conocimiento + motor de inferencia，推理分 hacia adelante 和 hacia atrás（§4）。

08从一组随机试验解出发，更好的解更可能被选为“父母”，后代组合父母的基因并可能突变，一代代改进。这是：

B。试验解叫 cromosoma，组成部分叫 gen；不保证找到解（§4）。

09按 §4，deep learning 的 RNA 和基本 machine learning 的 RNA 的主要区别是什么？

D。基本的 RNA 有 3 或 4 层（1–2 个隐藏层），deep learning 可以有几百个隐藏层，能处理大量非结构化、未标注的数据（§4）。

10机器人到了路口，往哪边走取决于它要去的地方；换一个目的地，不改规则就有新行为。它是哪种 agente？

B。它也叫 agente basado en metas：考虑动作的后果和目标，比反射型更灵活（§7）。要在多条可行路线里挑最快、最便宜的，才需要 utilidad。

11按 §6，下面哪种组合是 agente 环境最难的情况？

C。§6 列出的最难情况就是这四项；A 是最简单的情况。

12用 §8 的 Red a 网络（输出层阈值 .5，来自 H1、H2、H3 的权重分别是 1、−2、1），输入 [1, 0] 时，输出是多少？

A。H1：1·1 + 0·0 = 1 ≥ 1 → 1；H2：1·1 + 1·0 = 1 < 1.5 → 0；H3：0·1 + 1·0 = 0 < 1 → 0；输出：1·1 + (−2)·0 + 1·0 = 1 ≥ 0.5 → 1。神经元的输出只能是 0 或 1，所以 C、D 不可能（§8，可以用计算器验证）。
