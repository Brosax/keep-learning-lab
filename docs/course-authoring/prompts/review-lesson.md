# 提示词：审查一讲内容

用来抽查已经写好的讲次。可以交给另一个 AI 做独立审查。替换掉 `<…>` 部分即可。

---

请审查 Keep Learning Lab 课程 `<slug>` 的第 `<id>` 讲。

**输入：**
- 讲次数据：`content/<slug>.json` 中 `id` 为 `<id>` 的讲次
- 对应讲义：这一讲的 `resources` 和各段 `source` 指向的 `zh/<slug>/materials/` 文件和页码
- 规范：`docs/course-authoring/module-decision.md`、`docs/course-authoring/checklist.md`

**逐段检查：**
1. 打开 `source` 指向的页面。这一段说的内容在讲义里有吗？有没有讲错、讲偏，或者加入了讲义没有的结论？
2. 段落顺序和讲义一致吗？讲义里有重要小节被漏掉吗？
3. 有没有跨讲预支的内容？
4. 用的是老师的例子和术语吗？

**检查模块：**
5. 每个 `visual` / `codeDemo` / `exercise` 解释的是讲义的哪一页？去掉它会损失什么？
6. 有没有应该加图示或代码、但缺了的地方？

**检查自测题：**
7. 每道题的正确答案在讲义中有依据吗？解析有没有说清楚错误选项错在哪里？

**输出：** 问题清单。每条写清楚：位置（段落标题）、问题、讲义依据（页码）、建议改法。没有问题就明确写"无问题"。不要直接修改文件。
