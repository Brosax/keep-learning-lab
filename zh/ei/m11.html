Entornos inteligentes · 地图的终点

今天 computación y comunicación ubicua (ES) / ubiquitous computing and communication (EN)——泛在计算与通信已经实现。一个包含全部知识和信息的全局智能系统（la nube，云）与物理世界互动；物理世界由用户和几乎任何“cosa”（物）组成，这就是 Internet de las Cosas (ES) / Internet of Things, IoT (EN)——物联网。

历史背景：90 年代 Xerox 提倡 computación ubicua，即系统“溶解”在环境里、变得不可见。这需要元件微型化、无线传感器网络、超低功耗和新的交互方式，这些条件今天都已满足。

对应课程：EI（Entornos Inteligentes，就是本课）、CIUD（Ciudades inteligentes）。

Pilares · 信息社会的支柱

三根主柱：microelectrónica、informática、telecomunicaciones。其他重要支柱：系统与entorno（环境）以及与人的连接（factor humano，人的因素）、新的供电方式和 eficiencia energética（能效）、赋予系统计算inteligencia。

这场革命的几个关键：元件的微型化和集成（带来便携设备和海量传感器，即 sensorización）；抽象层次的设计思想（带来资源复用和互操作）；用科学方法设计和评估界面（usabilidad）；新网络带来的全球连接和移动性。

Miniaturización · 微型化

晶体管越做越小（ley de Moore），芯片上的功能越来越多，限制它的是功耗。由此有了 ASIC、FPGA、各种处理器和存储器。→ §2　→ §3 四种处理器（1.1.1）

硕士没有专门对应这一块的课程，可以把它看作 sistemas empotrados 的硬件基础。

Integración · 集成 硕士重心

把 CPU、存储器、E/S 端口，乃至模拟电路、MEMS 和通信模块做进一块芯片：microcontrolador、SoC。由此诞生了 sistemas empotrados 和 microcomputadores。→ §4（1.1.3、1.1.4）

对应课程（Sistemas empotrados 一行）：MICRO（Técnicas de diseño de sistemas empotrados basados en microcontroladores）、MICROK（Microkernels）、IMICRO（Intensificación en microcontroladores）、FPGA（Diseño de Sistemas Empotrados basados en FPGAs）、EMP（Microprocesadores empotrados）、DPCI（Diseño de placas de circuito impreso）。

sistemas empotrados 是在 §4 Integración 里定义的，所以对应它的这组课程放在这块。

Abstracción · 抽象层次

把复杂系统分成若干层，每层只用下一层提供的服务，不必知道它怎么实现。软件里就是从 código máquina 到 SOA 的编程层次，以及 SO、máquina virtual、virtualización、middleware。→ §5（1.1.6）　→ §6（1.1.2）

硕士覆盖多少：硕士不深入系统的高层编程（middleware 和应用），只讲“lo imprescindible”（必需的部分）。

Sensorización · 传感 硕士重心

传感器和执行器是电子系统与环境之间的接口。本章的重点是 sensor inteligente。→ §7（1.1.10）

对应课程：SENSOR（Del mundo físico al controlador: sensores, interfaces y comunicaciones）。BUSES（Laboratorio de Diseño de Aplicaciones de Transductores y su Interconexión con Buses de Campo）目前不开设（no se oferta）。

Energía · 能源

电网、电池、超级电容、燃料电池、能量收集。电池的发展没有跟上 ley de Moore，常常决定设备的成本和体积。→ §8（1.1.9）

对应课程：硕士没有专门对应这一块的课程。不过下面“硕士踏足范围”图的阴影把 Energía 一带（pilas、baterías、SuperCap、Harvesting Energy）也圈进了硕士范围。本课 Tema 2 的 M26 Consumo energético 会细讲。

Conectividad · 连接与移动性

从 BAN 到 WAN 的各种网络，有线和无线，以及所有网络向 Internet 技术的融合。→ §9（1.1.7）

对应课程：REDES1、REDES2（Tecnologías de redes de sensores I / II）。IREDES（Intensificación en redes de sensores）不开设。

Inteligencia · 智能

适应、学习、预测、按情境决策。从 sistemas expertos 到 machine learning、deep learning、IA generativa，以及 agente inteligente。→ §10（1.1.8）

对应课程：TAPI（Técnicas Avanzadas de Procesado de Información）。

Interacción · 交互

从命令行到 GUI 再到 NUI。好的界面要有 usabilidad，也要有 accesibilidad。→ §11（1.1.5）

对应课程：IUS（Interfaces de Usuario）、IPM（Interacción persona Máquina）、VISION（Visión Artificial）、TECA（Tecnologías Accesibles）。

Metodología de diseño · 设计方法

硬件和软件能实现的东西没有本质区别，codiseño hardware/software 就是在两者之间权衡。→ §12（1.1.11）

对应课程：MET（Planificación, gestión y desarrollo de proyectos）。IPN（Intensificación en planes de proyectos tecnológicos de negocio）不开设。

§2Miniaturización：从晶体管到处理器 背景

晶体管 1947 年发明。60 年代，Intel 的工程师 Gordon Moore 观察到：集成电路上的晶体管数每 18 个月翻一番。这个趋势长期成立，于是成了著名的 ley de Moore (ES) / Moore's law (EN)——摩尔定律。

易错点

“18 个月”这个数字要修正：实际趋势是每 2 年翻一番；2015 年以后周期拉长到 2.5–3 年。

晶体管数为什么能暴涨？靠 fotolitografía (ES) / photolithography (EN)——光刻：在硅衬底上一层层沉积金属或掺杂硅的 patrones（图形），这些图形构成晶体管。然后一层层往上搭：

要精确刻出图形，光的波长至少要和线条一样小，所以光刻用的波长越来越短；材料和结构的变化也在延续摩尔定律。CPU 的 feature size (EN)——特征尺寸（栅长）已小于 3 nm（IBM 2021 年宣布了 2 nm 技术）。代价是制造设备的成本飙升，但销量越来越大，厂商并没有停下。

极限是功耗。晶体管变小，本可以集成更多功能、跑得更快（栅长变小，电容效应也变小，时钟可以更快）。但功耗挡住了这条路：

CMOS 芯片的功耗

功耗正比于芯片的电容效应、时钟频率和电源电压平方的乘积：P ∝ C · f · V²

降功耗的办法：散热器、降低电源电压、新材料，以及 gestión energética inteligente（智能能耗管理）。处理器厂商在主频达到约 4 GHz 时放弃继续提频，转而在一块芯片里集成多个核：multicore (EN)——多核。

还有一个问题：晶体管太小时开关性能变差，不该导通时也会耗电（这通常叫漏电流 leakage）。

§3四种可编程处理器 1.1.1

四个缩写里，三个属于 §2 讲的“可编程芯片”，uC 则属于 §4 的集成。先看定义：

  • GPP (General Purpose Processor)——通用处理器：“procesadores de propósito general, también llamados microprocesadores”，也就是 microprocesador（微处理器）。本课里 procesador 和 microprocesador 两个词混用。
  • DSP (Digital Signal Processor)——数字信号处理器：专门做 proceso de señal（信号处理）。
  • GPU (Graphics Processing Unit)——图形处理器：专门处理 gráficos（图形）。有些资料这一章把 GPU 写作 Graphics Processor Unit；也有资料写作 Graphics Processing Unit。
  • uC / microcontrolador (ES) / microcontroller (EN)——微控制器：一块芯片里集成 CPU、存程序的存储器和一组 E/S（输入/输出）端口，构成一个小型可编程系统。通常很简单，但也可以带强大的事件管理、定时和通信模块。

四者都可编程，都执行指令序列（代码），区别在于为什么而优化。下表“细节”一列在 Tema 2 的 M25 Nodos 里会细讲：

处理器专长细节（M25）
GPP
microprocesador		什么程序都能跑PC 等应用平台的核心；指令集通用、寻址能力大；靠提频、缓存、多核等提速；灵活，但能效低
DSP信号处理为实时、密集的数据流计算优化；通常不用操作系统，把代码效率压到极致
GPU图形大规模并行：数千个 cores 以 SIMD（一条指令同时处理多个数据）方式工作，运行叫 shader 的小程序；tensor cores 用于 deep learning
uC
microcontrolador		单芯片的小型控制系统专用、面向控制；实时，响应确定，几个时钟周期内就能对外部事件作出反应；常直接访问硬件、不用 SO；集成定时器、ADC、PWM、串口等外设

§4Integración：SoC 与 sistema empotrado 1.1.31.1.4

一块芯片上只要集成 CPU、存程序的存储器和 E/S 端口，就是一个小型可编程系统，典型例子就是 microcontrolador（§3）。微电子还把越来越多“别的东西”做进了芯片：

  • 模拟部件：ADC (Analog Digital Converter)——模数转换器，以及比较器；
  • mixed signal IC (EN)——混合信号芯片：还集成放大器、滤波器和调制器；
  • MCP (Multilayer Multichip Package)——多芯片封装：把几块芯片装进同一个封装；
  • MEMS (MicroElectroMechanical Systems)——微机电系统：同样基于微电子工艺，集成机械、化学、光学甚至生物技术的微传感器和微执行器。
定义 · 1.1.3

SoC (System On Chip)——片上系统：一块超高集成度、高性能的芯片，可以包含多个 CPU（cores）、GPU、DSP、先进的通信模块（USB、Ethernet、Bluetooth、Wi-Fi……）、模拟部件、传感器等。今天很多电子设备（比如智能手机和平板）都基于 SoC。

和 microcontrolador 比：两者都是“一块芯片上的系统”。microcontrolador 通常很简单；SoC 的集成度和性能高得多，可以有多个、不同种类的处理器。

定义 · 1.1.4

sistema empotrado (ES) / embedded system (EN)——嵌入式系统：专用（propósito específico）的电子系统，通常（但不一定）嵌在一个更大的系统里；因为只为一个目的服务，通常在成本、功耗和尺寸上做了优化。microcontroladores 和 SoC 是这类系统的典型技术。

集成技术造就了两类系统。切换看它们的区别：

专用，而且到处都是：家电、报警系统、音视频播放器、数码相机、手机、手表、电子体温计、游戏机……汽车里可能有上百个专用处理器，控制发动机、刹车、稳定性、仪表盘、安全带；城市里有红绿灯、银行 ATM、地铁售票机和饮料机；办公室里有电话、打印机、复印机、存在检测器、门禁和监控。工业早就靠它们实现自动化。

关键词：propósito específico · inserto en otro sistema · optimizado en coste, consumo y tamaño。

microcomputador (ES)——微型计算机：基于 microprocesador 的通用计算机。特点：处理能力和寻址能力强（处理器的地址空间决定系统能用多少内存）；有内存管理（多任务、虚拟内存、数据保护）；有标准用户界面（显示器、键盘、鼠标）。分三类：

  • Servidores（服务器）：大存储、联网能力强、高性能、可扩展、可靠、容错；为网络上的客户端提供文件和程序。
  • PC：有面向专业用途的高性能平台（如图形工作站），但多数面向消费市场，性能和价格较低，越来越便携、小型化。
  • Dispositivos móviles（移动设备）：平板和智能手机。性能有限，靠高速连接云端弥补存储和计算的不足；交互方式新（触控、手势、触觉）。和它们配合的还有 wearables，比如 smartwatch 和增强现实眼镜。

Código máquina · 机器码

一长串 0 和 1，CPU 能懂，程序员却没法直接用。所有更高层的程序最后都要翻译成它。

00101101

例子：老的 Intel 386 处理器里，减法指令 SUB 的二进制码是 00101101。

Ensamblador · 汇编（低层）

用 mnemónicos（助记符）代替二进制码，直接对应处理器的指令集。缺点：写起来繁琐，而且每种 CPU 都不一样。

SUB AX, 5

示例：助记符 SUB 就是上一级那串二进制的“可读版”。

Lenguaje C · 中层

代码与 CPU 无关，同一份代码适用于任何 CPU，这叫 portabilidad (ES) / portability (EN)——可移植性。结构化、模块化的编程便于开发函数库，提高可维护性和生产率（指开发时间）。翻译它的程序叫 compilador (ES) / compiler (EN)——编译器。

int restar(int a, int b) {
  return a - b;
}

traductor（翻译器，如编译器）先把整个程序转成机器码再执行；intérprete（解释器）逐条转换、逐条执行。

C++ · 面向对象

C 这类语言的演进：OOP (Object-Oriented Programming)——面向对象编程，以及面向组件的编程。它方便代码复用（对象）和开发分布式应用。

class Termostato {
public:
  void ajustar(float grados);
  float leer() const;
};

示例：一个“恒温器”对象，别的程序可以直接复用它。

WSDL · 面向服务

再高一层是 programación orientada a servicios (ES)——面向服务的编程（SOA, Service-Oriented Architecture）：与平台和程序都无关，让不同的系统之间能交换信息，即 interoperabilidad (ES) / interoperability (EN)——互操作性。典型例子是 WSDL (Web Services Description Language)——Web 服务描述语言。

<operation name="leerTemperatura">
  <input message="tns:Peticion"/>
  <output message="tns:Respuesta"/>
</operation>

这段 WSDL 片段只描述“有一个读温度的操作，输入什么、输出什么”，不关心对方用什么语言、跑在什么平台上。WSDL 在 Tema 2 的 M21 §4 里还会出现。

更高层：可视化、无代码、AI 辅助

更进一步：programación visual（用方框图）、sin código（用配置界面）、asistida por IA（AI 辅助），以及 intuitiva（vibe coding）。

记住三句话
  • C：中层，与 CPU 无关（可移植），用编译器翻译。
  • C++：面向对象，便于代码复用和分布式应用。
  • WSDL：面向服务（SOA），与平台和程序都无关，实现互操作。

§6四种软件抽象层 1.1.2

SO、máquina virtual、virtualización、middleware 都是“抽象层”，但位置和作用各不相同。§5 的三列图只标出了 SO、middleware、aplicaciones 在编程层次里的位置；下图把四者画在同一台机器上。点击方块：

Aplicaciones · 应用程序

用户真正要用的程序。它们调用下层提供的服务，不需要直接面对硬件。

Middleware · 中间件

位于 SO 和应用程序之间，便于开发分布式、异构、复杂的系统，比如智能环境。Tema 2 的 M21 专门讲它。

右边的虚拟机 2 没有 middleware：它不是每个系统都必须有的一层。

SO · Sistema operativo · 操作系统

一段低层和中层的代码，让应用程序不必关心硬件（abstraerse del hardware）。它提供系统的各种例行功能，比如读键盘字符、在屏幕上显示数据、打印文件，应用程序员不用自己写。

Máquina virtual · 虚拟机

一个程序：在一台真实系统上模拟一个或多个系统，这些系统的 SO 可以相同，也可以不同（图中的 A 和 B）。

Virtualización · 虚拟化

在硬件和虚拟机的 SO 之间建立一个抽象层 VMM (Virtual Machine Monitor)——虚拟机监视器，用来在各台虚拟机之间动态分配硬件资源。

VMM 也常被称为 hypervisor / hipervisor。

Hardware · 真实系统

只有一套物理的 CPU、内存和 E/S。没有虚拟化时，SO 直接运行在它上面。

描述概念（点击揭晓）

máquina virtual 是被模拟出来的那个系统（一个程序）；virtualización 是在硬件和虚拟机 SO 之间建立 VMM、分配资源的那一层。middleware 则在 SO 之上、应用之下，和有没有虚拟化无关。

§7Sensorización：sensor inteligente 1.1.10

智能环境的电子系统通过 sensores（传感器）和 actuadores（执行器）与环境互动。sensor (ES/EN)——传感器：把物理量或化学量转换成电量的器件。种类很多（压力、温度、湿度、振动、光……），结构和工作原理差别很大。

按能量来源

Sensores pasivos

需要供电；被测量改变传感器的某个电参数（电阻、电容等）。

按能量来源

Sensores activos

压电、光电、射频等；被测量本身提供产生输出所需的能量。

有些资料按能量来源这样分：需要供电的叫 pasivos，被测量本身提供能量的叫 activos；也有资料把 active / passive 反过来用。

按结构，传感器分为 discretos、integrados 和 inteligentes 三种，后一种包含前一种。点按钮或图中的虚线框：

Sensor discreto · 分立式传感器

结构图里对应最左边单独的 “Sensor” 圆圈。一般指只有敏感/换能元件本身，输出原始的电信号，调理和模数转换都在外部电路里完成。

Sensor integrado · 集成式传感器

除了换能元件，还集成了把信号送进系统之前的调理级（acondicionamiento），有时还包括模数转换（图中 Conversión AD 是虚线框）。结构图列出的调理功能有五项：amplificación（放大）、filtrado（滤波）、linealización（线性化）、modulación（调制）、antirrebote（消抖，去掉开关触点的抖动）。

Sensor inteligente · 智能传感器

在集成式传感器的基础上，再加上处理能力和通信能力，通常向系统提供标准接口（例如 I2C、SPI 或 USB）。结构图里它的范围一直延伸到 Procesador，然后才接到 Sistema。

图的下半部分是反方向的执行器通道：系统的命令经 Procesador、Conversión DA（数模转换）和 Acondicionamiento 驱动 Actuador。

定义 · 1.1.10

sensor inteligente (ES) / smart sensor (EN)——智能传感器：在信号调理（和 A/D 转换）之上，增加了处理和通信能力的传感器，通常通过 I2C、SPI、USB 等标准接口接入系统。

一个很有意思的例子是 smartdust (EN)——智能尘埃：“motas” inteligentes，基于 MEMS 的微小传感器，通过无线网络自发地相互连接。

§8Energía：五种供电方式 1.1.9

智能环境中电子系统的电可以来自：red eléctrica（电网）、pilas 和 baterías（电池）、supercondensadores（超级电容）、pilas de combustible（燃料电池），甚至从环境中提取能量（energy harvesting）。点按钮，或点下面图里的椭圆：

Red eléctrica · 电网

供电质量好

接电网时要用电源，通常是开关电源 SMPS (Switching-Mode Power Supply)：把交流变成直流并稳压，保证系统得到良好的供电；往往还带软件控制，用来实现节能。微电子让这类电源大大缩小、效率更高。

局限：智能环境里很多设备接不上电网，要么因为会移动，要么因为附近没有电源。

Pilas y baterías · 电池

没跟上 ley de Moore

接不上电网时的常规方案。电池能量密度的发展没有遵循摩尔定律（见本节末的能量密度图），所以常常决定系统的成本和体积。为了延长续航，要用超低功耗的电子器件和节能技术（例如设定占空比 ciclos de trabajo，把暂时不用的部件关掉或休眠）。

pila 一般指一次性电池，batería 指可充电电池（batería recargable）。

Supercondensadores · SuperCap · 超级电容

新兴技术

和燃料电池一样，能降低电池的维护成本（更换和充电）。它的电荷密度小，但能承受几十万次充放电，寿命长得多。

另外，它的功率密度（W/kg）高、放电很快，但能量密度（Wh/kg）低（M26 细讲）。

Pilas de combustible · 燃料电池

新兴技术

它和超级电容并列为新兴技术，作用同样是降低电池的维护成本（更换和充电）。

另外，它的能量密度高，但功率密度低、放电慢（M26 细讲）。

燃料电池是什么：一般指通过电化学反应，把燃料（如氢、甲醇）的化学能直接变成电能，只要持续供应燃料就能发电，补充的是燃料而不是电。

Energy harvesting · 能量收集

只适合极低功耗

如果功耗非常小（很多智能环境的传感器网络就是这样），可以从环境中提取能量：光、热、振动、电磁波等，其中很多基于 MEMS 器件。

这类能量很少、多变、难以预测，最后通常要和电池或超级电容这样的储能器件配合使用（M26 细讲）。

方式什么时候用一句话区分
Red eléctrica设备固定、能接到电源SMPS 交流转直流并稳压，可软件节能
Pilas y baterías移动设备，或接不上电网没跟上摩尔定律，常决定成本和体积；靠低功耗和占空比延长续航
Supercondensadores想减少电池的更换和充电维护电荷密度小，但能充放电几十万次，寿命长
Pilas de combustible同上（新兴技术）能量密度高、功率密度低（见 M26）
Energy harvesting功耗非常小，例如传感器网络从光、热、振动、电磁波取能，常基于 MEMS；通常要配储能（见 M26）

§9Conectividad：五种网络 1.1.7

通信网络为电子设备的互连提供手段。典型的数据网是办公室的计算机网络，即 LAN (Local Area Network)——局域网。覆盖范围更大的有 MAN (Metropolitan Area Network) 和 WAN (Wide Area Network)，更小的有 PAN (Personal Area Network)——个人区域网和 BAN (Body Area Network)——人体区域网。点击下图的各个区域：

BAN · Body Area Network · 人体区域网

覆盖范围比 PAN 还小：连接各种穿戴式设备（dispositivos llevables）的网络就是 BAN；设备之间一般不需要超过 1–2 m。例子：贴在身上的小传感器测量生命体征，用 Bluetooth 之类的无线方式发给接收终端，终端再经 Internet、GPRS、UMTS 或 WLAN 发给医疗中心。

PAN / WPAN · 个人区域网

无线的个人区域网叫 WPAN (Wireless Personal Area Network)——无线个人区域网，典型例子是 Bluetooth。

有些资料把 PAN 的范围标为人身周围约一平方米；也有资料给出的 PAN 量级约为 10 m。

LAN / WLAN · 局域网

典型例子：一间办公室的计算机网络。无线的叫 WLAN (Wireless Local Area Network)——无线局域网，典型例子是 Wi-Fi。LAN 覆盖 10 m、100 m 到 1 km，即房间（room）、建筑（building）、校园（campus）。

MAN · 城域网

覆盖范围比 LAN 大：约 10 km，一座城市（city）。

WAN · 广域网

覆盖范围最大：100 km 到 1000 km，一个国家乃至一个大陆（country, continent）。

Internet 是最大的 WAN；4G、5G 这类蜂窝移动网也提供大范围覆盖。

按介质

Cableadas · 有线

líneas de datos（数据线）、líneas telefónicas（电话线）、fibra óptica（光纤），以及 PLC (Power Line Communications)——电力线通信：借用电力线传数据。

按介质

Inalámbricas · 无线

radio terrestre（地面无线电）、satélite（卫星）、infrarrojos（红外）。WLAN = Wi-Fi，WPAN = Bluetooth。WSN (Wireless Sensor Network，无线传感器网络) 用专门的拓扑和协议优化性能和功耗，例如 Zigbee。

拓扑

Topologías

bus（共享同一传输介质）、estrella / star（集中式、点对点应用）、árbol / tree（数据收集）、malla / mesh（能容忍链路和节点失效）；此外还有 ring（环形）和 hybrid（混合）。

有的网络带 QoS (Quality of Service)——服务质量机制，能保证带宽（速度）、误码率、延迟等通信参数；交互式服务离不开它。

网络的融合：几乎所有通信网络都在向一个基于 Internet 技术的全球系统融合（融合图见表下）：

§10Inteligencia：四种 IA 技术 1.1.8

智能环境能适应环境、学习、预测事件，并根据情境做决策，即 context awareness (EN)——情境感知。为此要用到人工智能（IA）技术，例如 RNA（Redes Neuronales Artificiales，人工神经网络）、lógica difusa（模糊逻辑）、algoritmos genéticos（遗传算法）。这些属于 Inteligencia Computacional（计算智能），是 IA 的一个分支。

1950–60 年代

Sistemas expertos

IA 的终极目标是模仿人的行为。当时讲专家系统，能像人一样推理。

1980 年代

Machine learning

目标没那么宏大：先用自动学习解决分类、预测和聚类。RNA 是其中一种技术，但当时算力不够。

2010 年代

Deep learning

云计算的大规模并行数据中心、先进的 RNA 架构和算法、专用芯片：语音和图像识别、自然语言处理、驾驶辅助终于好用了。

2020 年代

IA generativa

基于 deep learning 和基础模型，按需生成长文本、图像、视频、音频。例：GAN、LLM（如 GPT）。

§11Interacción：usabilidad 与 accesibilidad 1.1.5

随着电子和软件的进步，人和系统的交互方式一直在变：

最早

命令行 · 菜单

línea de comandos、selección por menú

→
图形

GUI

Graphical User Interface，基于 WIMP 范式（Window, Icon, Menu, Pointing device），以及 3D 和多点触控版本

→
自然

NUI

Natural User Interaction：语音、触觉和手势界面

好的界面要满足两个不同的标准。切换看看：

定义 · 1.1.5 · usabilidad

usabilidad (ES) / usability (EN)——可用性：界面对用户来说有效（eficaz）、高效（eficiente）、令人满意（satisfactoria）。它问的是：好不好用？

举个例子：智能家居 app 里调温度。能调成功，是有效；两步就能完成，是高效；用起来不烦，是满意。

定义 · 1.1.5 · accesibilidad

accesibilidad (ES) / accessibility (EN)——无障碍（可及性）：界面能被任何人使用，不论其技术、认知或身体能力如何。它问的是：谁都能用吗？

举个例子：同一个 app 支持读屏、语音控制、大字号，不熟悉手机的老人和视障用户也能调温度。

今天，界面的设计和评估有专门的方法，可以分成三部分来看：

左 · 谁在用

Interfaz de usuario

普通用户直接通过界面使用 producto o servicio（产品或服务）；残障用户可能还要经过一个 ayuda técnica（辅助技术）。这正是 accesibilidad 要考虑的。

中 · 好设计

Criterios de buen diseño

utilidad（有用）、eficiencia（高效）、seguridad（安全）、durabilidad（耐用）、estética adecuada（外观得当）、precio realista（价格合理），再加上 otros aspectos：entorno（环境）、actividad（活动）、perfil de usuario（用户画像）。做到了用户满意；做不到就会 abandono（弃用）或 infrautilización（用得不充分）。

右 · 过程

Ingeniería de la usabilidad y la accesibilidad

过程模型：análisis de requisitos（需求分析）→ diseño → implementación → lanzamiento（发布），并行有 prototipado（原型）和 evaluación（评估）；usuarios 在中心，每一步都回到用户。

趋势：

  • interfaces multimodales (ES)——多模态界面：组合人的多种感觉和运动通道，让交互更稳健、更自适应、更容错。运动通道是语音、面部和身体手势、目光；感觉通道是视觉、听觉、触觉（触压和动觉）、嗅觉、味觉和前庭觉。由此有了提升 experiencia del usuario（用户体验）的自然界面，以及改善无障碍的通用或自适应界面（interfaces universales o adaptativos）。
  • 与 IA 的新分支 computación afectiva (ES) / affective computing (EN)——情感计算结合，产生 avatares，即 ECA (Embodied Conversational Agent)——具身对话代理：人形的虚拟实体，能和用户进行自然、智能、带情感的对话。
  • 基于生理信号的界面，例如 BCI (Brain Computer Interaction)——脑机接口。
  • 泛在计算让人随时随地都能连接，因此需要换一种交互范式：自然交互和 interfaces tangibles（可触摸界面，即日常物品充当“隐形机器”的控件和显示器）。

§12Codiseño hardware/software 1.1.11

今天设计电子系统时，硬件能实现的和软件能实现的没有本质区别。一个功能用硬连线逻辑（lógica cableada）还是用代码来做，大多只是在几项设计指标之间权衡：prestaciones（性能）、consumo（功耗）、tamaño（尺寸），尤其是 flexibilidad（灵活性）。软硬件一起设计的方法叫 codiseño hardware/software (ES) / hardware/software co-design (EN)——软硬件协同设计。下面一步一步走一遍典型流程：

记住顺序

Especificación formal → Modelado ⇄ librería → [Simulación y verificación → Evaluación → Modificaciones y refinamientos → Modelado]（循环，划分和选处理器在这里做）→ Diseño verificado → Mapeado → Síntesis SW (C) ∥ Síntesis HW (VHDL) + interfacing → Implementación y prototipo（→ fabricación）。规格总在最前；验证通过之后才映射。

自测 12 题

根据本章内容编写的练习题。每题只能点一次，答完会显示解析。

01按 §3 的说法，“procesadores de propósito general”（GPP）又叫什么？

A。§3 的定义就是“también llamados microprocesadores”。microcontrolador 是 CPU + 存储 + E/S 的单芯片小系统，不是同义词（§3）。

02一块芯片上集成 CPU、程序存储器和 E/S 端口，常用于专用控制，能在几个时钟周期内响应外部事件。这是？

D。结构见 §4，实时、响应确定的特点见 §3 的表。GPU 擅长大规模并行，DSP 擅长实时信号处理，GPP 什么程序都能跑。

03在硬件和虚拟机的 SO 之间建立 VMM 抽象层、动态分配硬件资源的是？

C。virtualización 建立 VMM；máquina virtual 是在真实系统上模拟出来的系统本身；middleware 在 SO 和应用之间（§6）。

04关于 SoC，哪一项正确？

C。这是 SoC 的定义（§4，目标 1.1.3）。B 说的是 FPGA，D 说的是 MCP (Multilayer Multichip Package)。

05哪一项最符合 sistema empotrado 的定义？

B。§4，目标 1.1.4。A 描述的是 microcomputador；汽车只是嵌入式系统的一个例子。

06“界面能被任何人使用，不论其技术、认知或身体能力如何”，这是？

D。§11，目标 1.1.5。usabilidad 是有效、高效、令人满意，问的是“好不好用”。

07哪一个属于面向服务的编程层次：与平台和程序都无关，用于不同系统之间的互操作？

A。§5，目标 1.1.6。C 是中层、与 CPU 无关（可移植）；C++ 是面向对象，便于复用；ensamblador 是低层、每种 CPU 不同。

08借用电力线传输数据的有线通信网络是？

B。PLC = Power Line Communications（§9，目标 1.1.7）。WLAN（Wi-Fi）和 BAN 是无线网络，4G 是蜂窝移动网。

09“一个程序或系统：感知环境、处理信息、作出理性决定并据此行动；最简单的例子是恒温器。”这是？

A。§10，目标 1.1.8。自动决策算法只负责“选动作”；agente inteligente 是把感知、决策、行动连成闭环的完整系统。

10哪种供电方式电荷密度小，但能承受几十万次充放电、寿命长得多？

C。这是对 supercondensadores 的描述（§8，目标 1.1.9）。燃料电池正相反，能量密度高、功率密度低（§8）。

11sensor inteligente 比 sensor integrado 多了什么？

D。§7，目标 1.1.10。调理（以及有时的 A/D 转换）是 sensor integrado 就已经有的。

12codiseño hardware/software 的阶段顺序，哪一项正确？

B。§12，目标 1.1.11。仿真之后可以回到划分重新做，但规格总在最前，原型和制造在最后。
