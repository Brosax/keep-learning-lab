PWM

用定时器生成 PWM

9 个要点 阅读约 17 分钟

M31 里定时器只会"数到某个数就举手"（置 flag、请求中断）。这一章给每个比较通道接上一个unidad de salida (ES) / output unit (EN)——输出单元：TAR 每碰到一次比较值，硬件就直接改写一个引脚，不需要 CPU 插手。改写的规则由 OUTMOD 选择；选得合适，引脚上就是一串 PWM (Modulación de Anchura de Pulso) / pulse-width modulation——脉宽调制信号。

§0只有 0 和 1，怎样"半亮"？

数字引脚只能输出 0 V 或 VCC。怎样让一个 LED 只亮四分之一？Modulación de Anchura de Pulso: variar el ancho del pulso, no la amplitud.

D = t_on / T，平均值 = D · V_CC
LED

亮度与颜色

改 D 就改平均亮度；RGB LED 的三路各用一个 PWM，就能调出颜色。频率要足够高，人眼才看到"变暗"而不是"闪烁"。

servo

舵机角度

舵机（servomotor）的 PWM 周期固定 20 ms（50 Hz），角度由脉宽决定：1 ms → 0°、1.5 ms → 90°（中位）、2 ms → 180°。也就是占空比只在 5 %–10 % 之间变（见下图）。

motor

电机速度

直流电机的转速、经由 H 桥的方向控制都可以用 PWM（H 桥见 §4）。

PWM 固定周期、改变脉宽：占空比 D = ton / T 决定负载感受到的平均值。MSP430 的定时器可以在硬件里生成它。

§1输出单元 M32.1

定时器已经会数数了。怎样让它不经过 CPU，直接在引脚上"画"出波形？Modo comparación con salida: la cuenta modifica un pin de salida.

回忆 M31：TAxR 由定时器时钟驱动计数；每个 bloque de captura/comparación (ES) / capture/compare block (EN)——捕获/比较块里有一个 TAxCCRn，在比较模式下，TAxR 数到 TAxCCRn 时内部信号 EQUn 变成 1（同时置 CCIFG）。每个比较块还带一个输出单元：

引脚是固定的

哪个引脚能输出哪一路 OUTn（记作 TAx.n），由芯片决定，要查芯片的引脚功能表。例如 F5529 上 P1.7 = TA1.0、P2.0 = TA1.1、P2.1 = TA1.2。选定后：PxDIR 置 1（输出）、PxSEL 置 1（外设功能）。

输出单元 = TAxR + TAxCCRn + EQU0/EQUn + OUTMOD。TAxR 碰到比较值时，硬件按模式改写 OUTn，再送到引脚 TAx.n。

§2八种输出模式 M32.2 · M32.3

TAR 碰到 CCRn 的那一刻，引脚应该做什么？有 8 种答案。Los bits OUTMOD0–2 de TAxCCTLn seleccionan el modo de salida.

每个名字都是"EQUn 时做什么 / EQU0 时做什么"的缩写。记住这一点，表格就不用死背：

三条规则

modo 0

OUT 位

模式 0 下 OUTn 直接等于 TAxCCTLn 里的 OUT 位（bit 2），软件写多少就是多少，立即更新——相当于把这个引脚当成普通输出。

sincronismo

上升沿同步

除模式 0 外，OUTn 都在定时器时钟的上升沿改变，所以输出的边沿和计数严格对齐，不受 CPU 正在做什么影响。

usabilidad

OUT0 的限制

对输出单元 0 来说，EQUn 就是 EQU0。模式 2、3、6、7 要在同一时刻既"翻转/置 1"又"清 0/置 1"，没有意义，所以不能用于 OUT0。OUT0 只适合 0、1、4、5。

换成 up/down、continuous 计数

模式 4 算不算 PWM？

有些资料把能生成 PWM 的模式列为 2、3、4、6、7。模式 4 每个 EQUn 只翻转一次：在 up 模式（Escena 2 的第 4 行）里输出周期是定时器周期的两倍、高低各半，占空比固定 50 %，不能用 CCRn 调——它正适合 §5 的方波。在 up/down 模式（下图第 4 行）里 TAR 每周期经过 CCRn 两次，Toggle 也翻两次，得到以顶点为中心、宽度随 CCRn 变的脉冲——大概这就是有些资料把 4 算进去的原因。但模式 4 没有 EQU0 动作来"对齐"，哪一段为高取决于 OUT 的初值（下图用虚线画出了另一种），所以调占空比首选 2、3、6、7。在 §3 的探索器里切到 up/down、选 4、再切换 OUT 位就能看到。

continuous 模式

表格不变，变的是事件的位置：TAR 从 0 数到 0FFFFh 再回 0，周期固定 65 536 个时钟（回 0 时置 TAIFG）；EQUn 在 TAR = CCRn，EQU0 在 TAR = CCR0，不是回 0 的时刻。所以在下图里（CCR1 < CCR0）Toggle/Reset、Set/Reset 从 TAR = CCR1 高到 TAR = CCR0，Toggle/Set、Reset/Set 正好相反；Toggle 的输出周期是 2 × 65 536 个时钟。周期不能调，所以做可调 PWM 还是用 up 或 up/down（§3、§4）。

模式名 = "EQUn 动作 / EQU0 动作"。2、3、6、7 是可调占空比的 PWM 模式；模式 0 看 OUT 位；2、3、6、7 不能用于 OUT0。

§3up 模式的占空比 M32.4 · M32.5

CCR0 = 9、CCR1 = 3：高电平到底占 3 个时钟、6 个，还是 7 个？Ejemplo: TACCR0 = 9; TACCR1 = 3; salida OUT1.

把时间切成一格一格：每个计数值占一个定时器时钟。OUTn 在 "TAR 数到 CCRn" 和 "TAR 从 CCR0 回到 0" 的时刻改变。数格子就行：

把数格子的结果写成公式，就是下面四条：

周期 = (CCR0 + 1) 个时钟；Toggle/Reset、Set/Reset：D = (CCR0 − CCRn + 1)/(CCR0 + 1)；Toggle/Set、Reset/Set：D = CCRn/(CCR0 + 1)
最大占空比 = CCR0 / (CCR0 + 1)

记法：…/Set 结尾的模式在周期开头（EQU0）就是高，高电平从 0 数到 CCRn − 1，共 CCRn 格；…/Reset 结尾的模式在周期开头是低，高电平从 CCRn 数到 CCR0，共 CCR0 − CCRn + 1 格。CCR0 只管周期，CCRn 只管脉宽：改占空比不会改频率。

试试看

① 默认就是 Escena 3 的例子：模式 7，CCR0 = 9、CCRn = 3 → 30 %。换成 3，变成 70 %。② 把 CCRn 拉到 CCR0：模式 7 达到最大 90 %。③ 留意第一个周期：OUT 位的初值和稳态不一致时，第一个周期是不规则的，要等第一次 EQU0 才对齐（默认的模式 7、OUT 位 = 0 就是这样）。选模式 2 再打开 OUT 位，看第一个周期变成全低。④ 换到 OUT0，选模式 3：探索器会告诉你为什么不行。

up 模式：周期 = CCR0 + 1 个时钟；…/Reset 模式 D = (CCR0 − CCRn + 1)/(CCR0 + 1)，…/Set 模式 D = CCRn/(CCR0 + 1)，最大 CCR0/(CCR0 + 1)。

§4up/down：居中的脉冲 M32.6 · M32.7

同样的 CCRn，换成 up/down 计数，为什么 TAR 每个周期要碰到它两次？Modo ascendente/descendente: período 2·TAxCCR0.

up/down 模式里 TAR 从 0 数到 CCR0，再倒数回 0（M31）。一个周期是 2·CCR0 个时钟，而 TAR 在上行和下行时各经过 CCRn 一次，所以 EQUn 每周期出现两次，EQU0 只在顶点出现一次。以 CCR0 = 5、CCR1 = 3 为例：

周期 = 2·CCR0 个时钟；Toggle/Reset：CCRn/CCR0（只有偶数个时钟）；Set/Reset：(CCR0 + CCRn)/(2·CCR0)（≥ 50 %）；Toggle/Set：(CCR0 − CCRn)/CCR0（只有偶数个时钟）；Reset/Set：(CCR0 − CCRn)/(2·CCR0)（≤ 50 %）

括号里是各自的限制：两个 Toggle 类只有偶数个时钟（solo ciclos de trabajo con número par de ciclos），Set/Reset ≥ 50 %，Reset/Set ≤ 50 %。在探索器里切到 up/down 可以逐一验证。

两路输出之间的空档：dead time

up/down 的脉冲以顶点、谷底为中心。如果一路用"围绕顶点"的 Toggle/Set、另一路用"围绕谷底"的 Toggle/Reset，并让两个阈值错开，两路就永远不会同时为高，中间夹着一段两路都是低的 banda muerta (ES) / dead time (EN)——死区。下面以 CCR0 = 10、CCR1 = 7、CCR2 = 4 为例画出来：

把这两路接到一个 puente en H (ES) / H-bridge (EN)——H 桥上：Toggle/Reset 接 "Forwards"，Toggle/Set 接 "Reverse"，每路各驱动一条对角线上的两只三极管。

up/down：周期 2·CCR0，EQUn 每周期两次，脉冲以顶点或谷底为中心；Toggle 类只有偶数个时钟，Set/Reset ≥ 50 %，Reset/Set ≤ 50 %。两路错开阈值就得到死区，用于 H 桥：一路管正转对角线、一路管反转对角线，死区保证两组永不同时导通。

§5方波 M32.8

不需要调占空比，只要一个固定音调的方波。最省事的办法是什么？Generación de onda cuadrada: modo TOGGLE en la salida del bloque CCR0.

用 Toggle 模式，而且必须用 CCR0 那一路的输出（OUT0）。up 模式下 TAR 每 CCR0 + 1 个时钟回到 0 一次，每次 EQU0 翻转 OUT0，翻转两次才是一个完整周期：

f = f_clk / (2·(CCR0 + 1))
算一个音

SMCLK = 1 048 576 Hz（M24 的默认值），CCR0 = 1191：f = 1 048 576 / (2 × 1192) ≈ 439.8 Hz，接近标准音 A4（440 Hz）。反过来：CCR0 = fclk / (2f) − 1，取整。交替改变方波的周期和持续时间，就能拼出简单的"合成旋律"（音质不高）。

方波 = OUT0 + Toggle：每个 EQU0 翻转一次，f = fclk / (2·(CCR0 + 1))，占空比固定 50 %。

§6在 CCS 里配置 M32.9

从上电到引脚上出现 PWM，需要几行代码？之后 CPU 还要做什么？Configuración: pin, período, modo de salida, ciclo de trabajo, arranque.

不管哪种波形，配置都是同一个顺序。前五步对应 §1 那条链上的每个零件：

  1. 引脚：PxDIR |= BITy、PxSEL |= BITy，把 TAx.n 所在的引脚交给定时器。
  2. 周期：TAxCCR0（up：CCR0 + 1 个时钟；up/down：2·CCR0 个时钟）。
  3. 模式：TAxCCTLn = OUTMOD_x（§2 的表）。
  4. 脉宽：TAxCCRn（§3、§4 的公式）。
  5. 启动：TAxCTL = TASSEL_x + MC_x + TACLR——选时钟、选计数模式、清零。放在最后，计数从一个干净的起点开始。
  6. CPU 去睡觉：波形由硬件维持，不需要中断。只要所选时钟在该低功耗模式下仍在运行（Bloque 2 的 LPM），PWM 就照常输出。

两个例子：

WDTCTL   = WDTPW + WDTHOLD;             // 停 watchdogP1DIR   |= BIT7;                        // P1.7 设为输出……P1SEL   |= BIT7;                        // ……并交给外设：TA1.0 = OUT0TA1CCR0  = 1191;                        // 每 1192 个时钟翻转一次TA1CCTL0 = OUTMOD_4;                    // OUT0：ToggleTA1CTL   = TASSEL_2 + MC_1 + TACLR;     // SMCLK，up 模式，清零后开始__low_power_mode_0();                  // CPU 睡觉；SMCLK 在 LPM0 下仍运行
WDTCTL   = WDTPW + WDTHOLD;P2DIR   |= BIT0 + BIT1;                 // P2.0、P2.1 设为输出……P2SEL   |= BIT0 + BIT1;                 // ……外设功能：TA1.1、TA1.2TA1CCR0  = 400;                         // 周期 = 2 × 400 = 800 个时钟TA1CCR1  = 230;                         // OUT1：TAR 高于 230 时为高TA1CCR2  = 170;                         // OUT2：TAR 低于 170 时为高TA1CCTL1 = OUTMOD_6;                    // Toggle/SetTA1CCTL2 = OUTMOD_2;                    // Toggle/ResetTA1CTL   = TASSEL_2 + MC_3 + TACLR;     // SMCLK，up/down 模式__low_power_mode_0();

方波：f = 1 048 576 / (2 × 1192) ≈ 439.8 Hz。两路 + 死区：OUT1 = (400 − 230)/400 = 42.5 %，OUT2 = 170/400 = 42.5 %，每个周期两段死区，各 230 − 170 = 60 个时钟（SMCLK ≈ 1.05 MHz 时约 57 µs）。42.5 + 42.5 + 2 × 7.5 = 100 %。

运行中改参数

两条提醒：① TAxCCRn 没有缓冲，写入立即生效。运行中改 CCRn 可以直接改占空比，但新值如果正好跨过当前计数值，可能出现一个不规则的周期。② 换输出模式时，三位 OUTMOD 不要同时经过 000（模式 0），否则可能毛刺；安全做法是先 TAxCCTLn |= OUTMOD_7，再清掉不要的位。

配置顺序：引脚（PxDIR、PxSEL）→ 周期（TAxCCR0）→ 模式（OUTMOD）→ 脉宽（TAxCCRn）→ 启动（TAxCTL）。之后 CPU 可以睡觉，PWM 由硬件维持。

自测 12 题

根据本章内容编写的练习题。每题只能点一次，答完会显示解析。

01Timer 在比较模式下生成 PWM 时，OUTn 的每次变化是怎样完成的？

B。输出单元是硬件：TAxR 等于比较值时产生 EQUn/EQU0，按 OUTMOD 改写 OUTn，不需要 ISR（§1）。

02输出模式由哪里选择？

C。OUTMOD 是 TAxCCTLn 的第 7–5 位。MC 选的是计数模式，PxSEL 只是把引脚交给外设（§1、§2）。

03模式 6（Toggle/Set）在 EQUn 和 EQU0 时分别做什么？

A。名字就是"EQUn 动作 / EQU0 动作"。C 是模式 2，D 是模式 7（§2）。

04为什么模式 2、3、6、7 不能用于 OUT0？

D。这四种模式需要两个不同时刻的事件。OUT0 仍可用 0、1、4、5，方波正是用 OUT0 的 Toggle（§2、§5）。

05关于模式 0，哪一句是对的？

B。只有模式 0 不和定时器时钟同步；其余模式都在定时器时钟的上升沿改变 OUTn（§2）。

06up 模式，TAxCCR0 = 49、TAxCCR1 = 10，OUT1 用 Reset/Set。占空比是？

A。Reset/Set：CCRn/(CCR0 + 1) = 10/50 = 20 %。20.4 % 是忘了 +1（10/49）；80 % 是 Set/Reset 的结果（§3）。

07up 模式，TAxCCR0 = 99、TAxCCR2 = 25，OUT2 用 Set/Reset。占空比是？

C。(CCR0 − CCRn + 1)/(CCR0 + 1) = (99 − 25 + 1)/100 = 75 %：从 TAR = 25 到 99 共 75 格（§3）。

08up/down 模式，TAxCCR0 = 200。PWM 的周期是多少个定时器时钟？

C。up/down 的周期是 2·CCR0 = 400。201 是 up 模式的 CCR0 + 1（§4）。

09up/down 模式下，哪种输出模式得到的占空比一定 ≤ 50 %？

D。Reset/Set = (CCR0 − CCRn)/(2·CCR0) ≤ 50 %；Set/Reset 则 ≥ 50 %；两个 Toggle 类覆盖 0–100 %，但只有偶数个时钟（§4）。

10up/down 模式，TAxCCR0 = 500；OUT1 用 Toggle/Set、TAxCCR1 = 300，OUT2 用 Toggle/Reset、TAxCCR2 = 260。每段死区有多长？

B。OUT1 在 TAR 高于 300 时为高，OUT2 在低于 260 时为高；中间 300 − 260 = 40 个时钟两路都低，每周期两段（§4）。

11fclk = 32 768 Hz，up 模式，OUT0 用 Toggle，TAxCCR0 = 15。输出方波的频率是？

A。f = 32 768 / (2 × 16) = 1024 Hz。2048 Hz 是忘了除以 2；1092 Hz 是忘了 +1（§5）。

12定时器已经配置好（OUTMOD、CCR0、CCRn、TAxCTL），但引脚 P2.0（TA1.1）上没有波形。最可能漏了什么？

C。OUTn 要经过 PxSEL 才能到引脚；PWM 输出不需要中断，所以 GIE 和 ISR 都无关（§1、§6）。
