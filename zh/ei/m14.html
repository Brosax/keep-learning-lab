§1从 ARPANET 到“物”的互联网 1.4.1

IoT 不是某一天突然发明的，而是几条线慢慢汇合的结果：Internet 本身、informática ubicua (ES) / ubiquitous computing (EN)——泛在计算、RFID (Radio Frequency IDentification)——射频识别、M2M 遥测，以及后来的 CPS 和数字孪生。点「下一步」把时间线走一遍：

概览

为什么偏偏是这个时候？有四个推动因素，它们组合在一起，让“任何东西”都能接入 Internet：

1

Sistemas empotrados

各种能接入 Internet 的嵌入式系统。

2

WSN

redes de sensores inalámbricas (ES) / wireless sensor networks, WSN (EN)——无线传感器网络。

3

Orientación a servicios

面向服务的编程（M21 的 SOA 就是这条路线）。

4

Cloud Computing

云计算。要特别注意：WSN 计算和存储能力弱，正好由云来补足——两者互补。

于是什么都能联网：环境传感器、智能手机、心脏监护仪、家居设备、工业设备、停车计时器、自动售货机、超市货架、汽车、轮胎，甚至一头奶牛。

把这些“物”组织起来的是什么？可以把 IoT 的基础画成一棵树：根是技术，树干是软件，树冠是应用。点每一层：

Technology · 技术（树根）

三类基础技术：Sensing——感知（加速度计、磁力计、陀螺仪、气压、高度计、温度等传感器）；Embedded Processing——嵌入式处理（MCU、MPU、MCU/MPU 混合、网络处理器）；Connectivity——连接（NFC、6LoWPAN、Sub-GHz、ZigBee、GPS、BT/BTLE、Wi-Fi、RFID、蜂窝网）。其中的 6LoWPAN 就是 §9 讲的“低功耗网络上的 IPv6”。

Software · 软件（树干）

把底层的感知、处理、连接能力输送到上层的各种应用。

Applications · 应用（树冠）

Smart Grid、Smart Lighting、Smart Cars、Smart Tags、Smart Health、Smart Energy、Smart Parking、Smart Homes，以及 M2M、楼宇自动化（BLDG Automation）、空气质量监控、供应链自动化、行人导航（Pedestrian Navigation）、汽车安全（Auto Safety）、Remote Appliance Avoidance……中间写着 “Many other services”。注意 M2M 在这里是众多应用之一，和 §2 “M2M 只是 IoT 的一部分”一致。

Technology Innovations · 技术创新

让这棵树长起来的技术进步：小型化和封装技术的进步、flash 存储的进步、强大而又便宜、低功耗的新一代 MCU、基于云的服务。可以和上面的四个推动因素对照：嵌入式系统、WSN、面向服务、云计算。

“y más allá”：Internet 带来的其他创新

章名里的“más allá”指的就是这些。

Web 的形态

web 2.0（2004）：协作式，社交网络、博客、wiki、YouTube。
web 3.0 / web semántica：给数据加上含义和用途（metadatos）。
web3：用 blockchain 类技术让 web 去中心化。

数据与智能

搜索引擎；Cloud computing；Big Data（§5）；Deep learning：让网络从海量信息中学习，形成自适应的智能系统。

连接物理世界

IoT；Cyber-physical systems（背后是 Industria 4.0）；Digital twins；Metaverso：虚拟与增强现实 + 社交网络 + IoT。还有 Second Life（2003）、Google Earth（2005）、Street View（2007）改变了人们对虚拟空间的感受。

§2IoT 与 M2M 1.4.2

定义 · IoT（UIT）

UIT (ES) / ITU (EN)——国际电信联盟（Unión Internacional de Telecomunicaciones）：IoT 是信息社会的一种全球基础设施——“infraestructura mundial de la sociedad de la información”——它利用现有的和不断演进的、可互操作的 TIC (ES) / ICT (EN)——信息通信技术，把物理的和虚拟的“物”互联起来，提供高级服务。

这个定义 2012 年 7 月 4 日发布；UIT 强调 IoT 是一种“visión”，不是单一技术。在 IoT 里，“物”和人处在同一层级，可以像人一样被识别。

定义 · M2M（oneM2M）

M2M (Machine To Machine)——机器对机器：“combinación de dispositivos, software y servicios que funcionan con una intervención humana escasa o nula”，即设备、软件和服务的组合，运行时几乎不需要人工干预。

两者什么关系？答案很直接：常有人把 M2M 和 IoT 混为一谈，但 M2M 只是 IoT 的一部分。有人说它是 IoT 的 facilitador（推动者），也有人说它是 IoT 的“tuberías”（管道）。换个角度说也一样：M2M 可能是 IoT “最早的形态”，主要在 B2B 市场，是 IoT 的重要推动者。

M2M

机器之间的自动通信

遥测和工业控制是它的前身；通常用于企业之间（B2B）。部署者事先知道要拿数据做什么，数据归部署者所有。

IoT

连接一切，并加上情境

还包括本身不智能的物体：通过手机读二维码、RFID、NFC 把它们带进网络，再加上地理位置等情境。数据是开放的，不知道谁会用、用来做什么。

补充 上面两格里“数据归谁”“非智能物体”的对比，是 Nick Gall（Gartner）和 Usman Haque（Pachube/Cosm）的观点；Gall 的结论是 M2M 是 IoT 的一个子领域。

§1 末尾那幅拼图右下角的三轴图说的就是这一步：以前的连接是 anytime、any place，现在多了第三个轴 anything。补充 2005 年 UIT 的报告 The Internet of Things 把它形容为“一个新维度”，并列出 IoT 的四项使能技术：RFID、传感器、smart things（物体内嵌智能）、微型化与纳米技术。

Any TIME

移动中、室内和室外、白天和夜里。

Any PLACE

移动中、户外、室内（离开 PC）、在 PC 前。

Any THING

PC 之间、人对人（H2H，不用 PC）、人对物（H2T，用通用设备）、物对物（T2T）。

还有一个说法叫 Internet of Everything（¿Qué será?）。补充 这是 Cisco 提出的说法，把人、流程、数据和物都连起来。

§3CPS 与 gemelo digital 1.4.2

定义 · CPS

sistema ciberfísico (ES) / cyber-physical system, CPS (EN)——信息物理系统：物理的、生物的和人工的系统，其运行由一个 “núcleo informático”（计算核心）来集成、监督和/或控制。这个词由美国 NSF 的 Helen Gill 在 2006 年提出，指计算与物理过程的集成。

在 CPS 里，嵌入式系统和网络实时监控物理过程，通常带有 bucles de realimentación——反馈回路：物理过程影响计算，计算也反过来影响物理过程。

Computational Platform A · 计算平台 A

一台嵌入式计算机。它只有一条来自物理对象的输入（相当于通过传感器测量），输出只送进网络——A 自己不直接动作物理对象。

Network Fabric · 通信网络

图里网络是单向的：A → Network Fabric → B。两台嵌入式计算机“entre ellos a través de una red de comunicaciones”交互。CPS 是联网的系统，不是一台孤立的控制器。

Computational Platform B · 计算平台 B

有两条输入：来自网络（A 的结果）和来自物理对象（自己的测量）；它的输出回到物理对象（相当于通过执行器动作）。于是形成两个反馈回路：Plant → A → 网络 → B → Plant，以及 Plant → B → Plant。

Physical Plant · 物理对象

被监控的物理过程。图里没有单独画传感器、执行器的方框：计算机通过“sensores y actuadores”和物理对象交互，就是这些进出 Physical Plant 的箭头——出来的是测量，进去的是动作。物理过程影响计算，计算也反过来影响物理过程。

CPS 会成为航空航天、交通、工业制造、医疗等领域许多新技术的关键：将来任何物体或结构都会内嵌计算、通信和控制能力。

别混淆

CPS ≠ ciberespacio

CPS 常被误认为和 ciberespacio——赛博空间（计算机创造的虚拟领域）有关。其实两者只是都来自 cibernética——控制论：数学家 Norbert Wiener 推广的、研究机器和人中控制与通信的科学（希腊语 kybernetes＝舵手）。

别混淆

CPS、IoT、Industria 4.0

三者都把物理世界和计算世界连起来。区别：CPS 是理论概念，不谈具体实现或应用；IoT 基于 Internet 技术；Industria 4.0 面向工业应用。

Industria 4.0

第四次工业革命

德国政府 2011 年提出：以 CPS 为基础，利用 IoT、cloud computing、big data、deep learning 等新技术，带来更高的生产率、灵活性和敏捷性。

为什么叫“4.0”？把四次工业革命排成一道台阶，越往右越晚、越往上越复杂。点每一级台阶：

1.ª revolución industrial · 18 世纪末

引入水力和蒸汽驱动的机械化生产设施。标志：第一台机械织机（first mechanical loom），1784 年。

2.ª revolución industrial · 20 世纪初

基于劳动分工、用电力驱动的大规模生产。标志：第一条生产线，Cincinnati 的屠宰场，1870 年。

3.ª revolución industrial · 1970 年代初

用电子和 IT 让制造进一步自动化。标志：第一台可编程逻辑控制器 PLC (Programmable Logic Controller)——可编程逻辑控制器，Modicon 084，1969 年。

4.ª revolución industrial · 今天

以 Cyber-Physical Systems 为基础——这就是 Industria 4.0。它利用 IoT、cloud computing、big data、deep learning，提高生产率、灵活性和敏捷性。

定义 · Digital twin

gemelo digital (ES) / digital twin (EN)——数字孪生：一个对象或系统的虚拟表示，覆盖它的整个生命周期，用实时数据更新，并用仿真、machine learning 和推理来辅助决策。它可以看作物理世界与虚拟世界之间的双向结合，用来做智能数据分析和系统监控。

要记住：它比 CPS 更进一步（“un paso más allá”）。简短版：通过传感器或自动化装置获得的信息，建立一个过程、产品或服务的虚拟模型。

读图：真实产品把数据送进虚拟空间；虚拟空间里的模型经过分析、仿真后，把信息和流程送回真实空间，指导真实产品的制造和运行。两边是同一个对象的两份“孪生”。

来历：David Gelernter 1992 年的书 Mirror Worlds 里已经有这个想法；Michael Grieves 2003 年最早把它用于工业制造；NASA 的 John Vickers（Grieves 的合作者）2010 年创造了 digital twin 这个词。其实 NASA 在 1960 年代的太空任务中已经在用这个概念。

应用：一个很有前景的方向——人或某个器官的数字孪生：模拟你的生理状态，用植入的纳米传感器提供真实数据来预测健康，必要时通过纳米执行器干预。

补充 “Sin datos reales, no hay digital twin”：传感器实时采集数据 → 云端处理并与情境参数比较 → 先在虚拟中修改，满足要求后才实际生产。好处：在问题发生前避免它、减少停机、通过仿真规划未来、按客户要求定制生产。

有些资料说 digital twin 这个词是 NASA 的 John Vickers 在 2010 年创造的；也有资料说是 NASA 在 2012 年。

§4四个概念放在一起比 1.4.2

切换看每个概念的一句话定义、重点和例子：

一句话

信息社会的全球基础设施，用 ICT 把物理和虚拟的“物”互联，提供高级服务（UIT）。

重点

基于 Internet 技术；连接“任何东西”；“物”和人同一层级。

例子

监测环境的 WSN、smart grids、smart cities 和 smart homes（节能、服务管理、安全）。

一句话

设备、软件和服务的组合，几乎不需要人工干预（oneM2M）。

重点

机器之间的自动通信；IoT 的一部分、它的“管道”；B2B。

例子

2000 年代初用蜂窝调制解调器监控自动售货机、水泵；1980 年代的 Mobitex 遥测。

一句话

运行由 núcleo informático 集成、监督和/或控制的物理、生物和人工系统。

重点

计算与物理过程的集成；实时 + 反馈回路；是一个理论概念。

例子

Industria 4.0；航空航天、交通、工业制造、医疗。

一句话

对象或系统的虚拟表示，覆盖生命周期，用实时数据更新，用仿真、ML 和推理辅助决策。

重点

物理 ↔ 虚拟双向；比 CPS 更进一步。

例子

人或器官的数字孪生；预防机器故障、按需定制生产（补充）。

补充 · M2M 与 CPS 对比

只有 CPS 具备的特征

跨域通信流、确定性时延的通信流、多域数据源、跨域的多种数据分辨率、分布式实时/自主控制。

补充 · M2M 与 CPS 对比

只有 M2M 具备的特征

标准制定组织：M2M 的标准化已经在 3GPP、ETSI、IEEE、TIA 等组织推进；CPS 还需要理论和技术上的突破。

一句话记住

M2M 重“连”，CPS 重“控”

M2M 强调在很少人工干预下的连接；CPS 强调闭环/实时控制和高度自动化。

§5Big Data 1.4.3

定义 · 1.4.3

Big Data (ES/EN)——大数据：一组技术和策略的集合，能够以经济的方式（de forma económica）、高速地采集和分析来自多个异构来源的大量数据。

这个定义摆出了 Big Data 著名的三个 “v”，但还缺一个变量。点开看：

Volumen · 量大

数据无处不在：条形码、信用卡、手机基站、水表电表、传感器，以及人们在社交网络上产生的海量内容。

补充 “多大才算 Big”没有统一标准：有的说“超过 1 TB”，也有的说“超过‘普通’的 GB 级”。

Velocidad · 快

数据产生得快，也要分析得快（a una alta velocidad）。几个数字：每分钟发出 2 亿多封 email、Google 上 200 万次搜索、Instagram 上传 3 600 张照片、YouTube 上 48 小时视频。

Variedad · 杂

来自多个异构来源：既有结构化数据（机器能直接处理），也有非结构化数据。来源包括企业和政府（Open Data 运动希望公开这些数据）、社交网络，以及装满传感器的智能手机。

第四个变量

三个 v 之外，“falta una cuarta variable: el tiempo real”——还缺第四个变量：实时。例如 Amazon、Google、Facebook、Twitter 能实时生成成千上万条个性化推荐。

Big Data 的价值不在“多”，而在把大量数据变成智能。这一步靠 Ciencia de los Datos——数据科学：

数据

传感器（低功耗、降价、无线通信 → WSN）、web social、Open Data，以及用开源硬件自己造联网设备的公民。

→
Big Data

经济、高速地采集和分析。Google 为索引整个 Internet 创造的底层技术就是今天的 Hadoop。背后要有 Cloud Computing。

→
智能

实时个性化推荐、预测模型、医疗、保险、零售中的个性化；再用可视化把数据变成业务。

总结一下：1980 年代是 PC 革命，1990 年代是 Internet 革命，新世纪带来 Web 2.0，现在是数据革命。

§6Smart grid：会“思考”的电网 1.4.4

定义 · 1.4.4

smart grid (EN) / red eléctrica inteligente (ES)——智能电网：新一代电网，能够预测所有接入用户（生产者、消费者和 prosumidores——既生产又消费的产消者）的行为，并智能地、经济有效地作出响应，从而提供一个经济高效、可持续、低损耗的电力系统，具备高水平的质量、供电可用性（disponibilidad en el suministro）和安全。

简单说：smart grid 用来提高节能和能效。

为什么非要 smart grid？电网最大的挑战是大规模引入 TIC；只有这样，欧洲才能完成 objetivo 20/20/20：

CO₂

−20%

排放比 1990 年减少 20%。

能耗

−20%

能源消耗减少 20%。

可再生

20%

能源中 20% 来自可再生能源。

还有两件事：一是标准化，让众多技术、流程和参与者能互操作——欧盟委员会 2011 年向 CEN、CENELEC、ETSI 下达 mandato M/490，要求它们确定和完善 smart grid 的标准；二是智能电表（Smart Meters），用户会因此成为 20/20/20 承诺中主动的一方。

“generación-distribución-uso” 的模式几十年没变：信息单向流动，家庭的用电情况不反馈回来。发电能力和消费不平衡，部分电能就浪费了。

Smart Energy Grid 打破单向结构，改成双向通信，实时让生产匹配消费，改善配电、降低开支。前提是家里有能测量瞬时用电、并能接入网络的设备；电表读数可以从一个月一次变成每 15 分钟一次。

§7Smart city 1.4.5

定义 · 1.4.5

smart city (EN) / ciudad inteligente (ES)——智慧城市：技术部署在城市的街道上，用来提升向市民提供的服务的质量和管理，从而带来更高的生活质量的城市。

smart cities 和 smart homes 都是 IoT 的重要应用：节能与能效、服务管理、安全等。

更完整的定义 补充

smart city 用 TIC 让它的关键基础设施、组成部分和公共服务更具互动性、更高效，并让市民更了解它们。

  • 它和 IoT 紧密相连：两者都以 M2M 通信为基础，所以 smart city 被称为“IoT 的第一步”。
  • 描述性的说法：一个拥有数以百万计的传感器和执行器的城市空间，其中也包括人和他们的手机；城市能“听懂”正在发生什么，从而做出更好的决策。
  • “smart”不是一个达成就结束的目标，而是各方持续改进的过程。
为什么 · 补充

城市的分量

2007 年 7 月城市人口超过农村人口；到 2050 年约 70% 的人口住在城市。城市只占全球 2% 的土地，却消耗约 75% 的能源，产生约 80% 的温室气体。

做什么 · 补充

常见的领域

城市交通、能效与环境、基础设施和公共建筑管理、政府与市民、公共安全、健康、教育与文化、电子商务。

怎么做 · 补充

整体规划

要有城市的整体视角，按优先级逐步部署服务，避免形成互不相通的信息孤岛；模式可以是纯公共的，也可以是公私合作。

Santander 的项目。点开每个项目：

SmartSantander · 最重要的项目

欧盟资助，投资 880 万欧元，合作方包括 Telefónica、Alcatel、Ericsson、TTI Norte、Universidad de Cantabria 等。目标是在城市里部署一个全球独一无二的实验平台：在全城安装 20 000 个传感器，用来试验 smart city 的典型应用和服务（其中 Santander 本地 12 000 个 IoT 设备，另在 Belgrado、Guildford、Lübeck 部署）。第一年已部署 3 000 个。

  • 停车：传感器检测路面空车位，通过面板、手机应用（iOS、Android）或 GPS 引导司机。
  • 智能灌溉：在 parque de las Llamas 优化用水。
  • 增强现实：用二维码和 NFC 标签提供旅游、商业、古迹信息，整座城市变成信息点。
  • 参与式感知（“pace of the city”）：市民用智能手机充当移动传感器。
  • 移动感知：在市政车辆、出租车、公交车、警车上装传感器，测量环境参数。

OutSmart · 能效

欧洲项目，在 Santander 应用于公共照明。其他参与城市各有方向：Berlín（垃圾收集）、Birmingham（交通，特别是自行车）、Trento（水资源）、Aarhus（下水道和水）。

Burba · 智能垃圾收集

在一个街区试验“智能”垃圾箱：测量各种参数，用来规划收运路线、确定所需垃圾箱和车辆的数量、选择最合适的收运时间。参与方来自中国、意大利、葡萄牙和西班牙。

Smart Search · “活的橱窗”

开发一个搜索引擎，为 IoT 提供情境：把 Internet 上发生的事（社交网络）和街上发生的事（摄像头的实时图像）联系起来，还可以叠加 SmartSantander 的交通、环境数据。预算 410 万欧元（欧盟出 270 万），为期 36 个月。

Pago NFC · 手机支付

西班牙首创的试点：先在公共交通、商店和 Universidad de Cantabria 校园用手机贴近终端付款，SIM 卡变成能存多张银行卡的虚拟钱包；之后扩展到市政服务，如预订体育设施、缴纳市政税费、OLA 停车费、图书馆。

Red de Ciudades Inteligentes · 智慧城市网络

由 Santander 主持，成员包括 Logroño、Madrid、Barcelona、Sevilla、Valencia、Málaga 等。目的：交流经验；推动用新技术改善公共服务；为企业建立稳定的法律框架，让一个城市开发的应用能用于全国市场；联合申请欧洲资金、节约成本。

Málaga Smart City 补充

Málaga 是 Santander 智慧城市网络的成员；它的能源项目被称为能效和能源管理领域世界级的参考。项目 2009 年启动，预算 3 100 万欧元，为期四年，包括四条线：

Smart Grids

配电的智能管理：智能电表、远程管理，实时、自动地操作配电网。

Smart Generation and Storage

可再生能源的自发电和储能：公共建筑装光伏、酒店用微型发电、微型风电；电池储能供建筑空调、公共照明和电动交通使用。

Smart Energy Management

终端用能的高效管理；推广电动汽车，安装充电桩、组建车队。

Smart and Informed Customer

让用户掌握用电数据，第一次成为电力系统中主动的一方，负责任地用电。

当时已受益的用户：300 个工业用户、900 家服务业企业、11 000 个家庭用户。目标是落实欧盟 20/20/20 计划，对 Málaga 来说相当于每年少排放 6 000 吨 CO₂。

§9IPv4 与 IPv6 1.4.7ejercicio

先说清楚

这个目标标注为 ejercicio：先看 IPv6 和 IoT 的几条要点，再用对比表、计算器和地址转换器练习。

要点
  • 设备数爆炸。按 Cisco 2011 年的预测，联网设备 2010 年 125 亿、2015 年 250 亿、2020 年 500 亿，而世界人口只有 68 亿、72 亿、76 亿（下表）。IPv4 的约 43 亿个地址显然不够分。
  • IPv6 是实现 IoT 的关键。2015 年约 250 亿、2020 年约 500 亿台设备联网的预测，是在 UIT 2013 年一场题为“La necesidad de más direcciones IP”（需要更多 IP 地址）的会议上发布的；部署 IPv6 被认为对实现 IoT 必不可少。
  • §1 那棵 IoT 树的 Connectivity 一栏也列出了 6LoWPAN。IETF 为 IoT 制定的协议包括：低功耗无线个域网上的 IPv6、低功耗有损网络的 IPv6 路由协议、受限应用协议。M23 Redes 会讲到其中的 6LoWPAN 和 CoAP。
  • 补充 云、传感器、新的 IPv6 协议、开源硬件和智能手机共同推动 IoT；Steven Leibson 说，“podríamos asignar una dirección IPv6 a cada átomo en la superficie de la tierra”，而且还够再分给 100 个地球。

64 位预设的含义：IPv6 地址通常分成 64 位网络前缀和 64 位接口标识，所以一个子网就有 264 个地址。

地址写法转换：输入一个 IPv4 或 IPv6 地址，看它的完整写法、压缩写法和二进制。

IPv6 每组开头的 0 可以省略；连续两组以上的全 0 可以用 :: 代替，但一个地址里 :: 只能出现一次（否则不知道每处代表几组）。规范写法（RFC 5952）用小写字母，并压缩最长的那一段 0。“类型提示”只识别几类常见的特殊地址。

低功耗 IoT 网络—6LoWPAN：在 IEEE 802.15.4 上传 IPv6（见 M23 Redes）

为什么低功耗 IoT 网络要专门的 6LoWPAN？IPv6 路由器不像 IPv4 路由器那样对外发的包分片；所有链路的最小 MTU 是 1 280 字节，而 IEEE 802.15.4 整帧只有 127 字节，40 字节的 IPv6 固定报头占去很大一块，所以要有 6LoWPAN 适配层来分片重组、压缩报头。

两个日期：IANA 在 2011 年 2 月分配完最后的 IPv4 地址块；2011 年 6 月 8 日是 World IPv6 Day，各大网站一起做了 24 小时的 IPv6 试运行。

01按 §1 的时间线，“Internet de las cosas”这个说法是谁创造的？

C。1999 年成立的 Auto-ID Center 团队创造了这个说法（§1）。Weiser 对应泛在计算，Gill 对应 CPS，Vickers 对应 digital twin。

02IoT 起步时想做的是什么？

B。IoT 开始时想的就是给任何物体加上可从 Internet 读取的标签，比如给奶牛挂 RFID 来定位（§1）。A 是 WWW，D 是 web3，C 正好相反：工业自动化是从私有方案转向 IP。

03“Combinación de dispositivos, software y servicios que funcionan con una intervención humana escasa o nula”是哪个概念的定义？

D。oneM2M 对 M2M 的定义（§2）。UIT 对 IoT 的定义关键词是 “infraestructura mundial de la sociedad de la información”。

04M2M 和 IoT 是什么关系？

A。常有人把 M2M 和 IoT 混淆，但 M2M 只是 IoT 的一部分（§2）。

05关于 CPS，哪一项正确？

C。见 §3。A 是常见误解；2011 年德国提出的是 Industria 4.0；CPS 恰恰有反馈回路，计算和物理过程互相影响。

06下面哪一项描述的是 gemelo digital？

D。数字孪生的定义（§3、§4）。A 是 CPS，B 是 IoT，C 是 M2M。

07Big Data 的定义是？

A。§5 的定义。deep learning 是 §1 “y más allá” 里列出的另一项创新。

08smart grid 和传统电网的关键区别是？

B。§6 的定义：传统电网信息单向，smart grid 改成双向。D 描述的正是传统电网。

09按 §7 的定义，smart city 是？

A。§7 的定义。

10SmartSantander 项目的核心是什么？

B。A 是 NFC 试点，C 是 Smart Search，D 是 Burba（§8）。

11Málaga Smart City 主要聚焦什么？

D。见 §8 的 Málaga Smart City。A、B、C 都是 Santander 的项目。

12IPv6 的地址数量是 IPv4 的多少倍？

C。2128 ÷ 232 = 296 ≈ 7.9 × 1028。4 倍是位数之比，不是地址数之比（§9）。
